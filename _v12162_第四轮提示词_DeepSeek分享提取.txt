## 修改二：`view.errors` 跨圈累积

**位置**：`MetaDGTF._run_layer` 的圈循环 + `MetaDGTF._finalize_layer_common` 的收尾回填。

**根因**：`_run_layer` 每圈新建 `DGTF` 实例、每圈返回的 `view` 是**该圈独立的对象**，循环结束后只保留最后一个 `view`。中间圈的 `view.errors`（包括 P1-6 写入的「deferral 被拦」）随 view 一起被丢弃。`pool.meta` 跨圈累积，但 `pool.meta` 不进产物。

**改法**：在 `_run_layer` 的圈循环里，每圈结束后把 `view.errors` 收集到一个跨圈列表；在 `_finalize_layer_common` 里把这个列表合并回最终 view。

### 第一步：`_run_layer` 的循环内收集

在 `_run_layer` 方法开头（`view = None` 附近）加一个累积列表：

**查找**（`_run_layer` 内，约在 `view = None` 那一行附近）：

```python
        view = None
        prev_product = ""
```

**替换为**：

```python
        view = None
        prev_product = ""
        # [P1-6 补] 跨圈累积 view.errors —— 每圈新建 view、只 return 最后
        # 一圈，中间圈的 errors（含 deferral 被拦留痕）会随 view 丢弃。
        # 这里逐圈收集，收尾时合并回最终 view。
        _all_view_errors: List[str] = []
```

然后在圈循环里，`view = dg.run(inp)` 之后、`view.rounds_run = layer_no` 附近，加上收集语句：

**查找**（`_run_layer` 内）：

```python
            dg = DGTF(entry, self.llm, self.config)
            view = dg.run(inp)
            view.rounds_run = layer_no
```

**替换为**：

```python
            dg = DGTF(entry, self.llm, self.config)
            view = dg.run(inp)
            view.rounds_run = layer_no
            # [P1-6 补] 逐圈收集 errors（去重，保留首次出现的）
            for _err in (view.errors or []):
                if _err not in _all_view_errors:
                    _all_view_errors.append(_err)
```

### 第二步：把累积列表传进 `_finalize_layer_common`

`_run_layer` 末尾调用 `_finalize_layer_common` 的 state dict 里加一个键：

**查找**（`_run_layer` 内）：

```python

                "roles_hist": roles_hist,
```

**替换为**：

```python
            self._finalize_layer_common(entry, view, {
                "roles_hist": roles_hist,
                "all_view_errors": _all_view_errors,
```

### 第三步：`_finalize_layer_common` 里合并 errors

在 `_finalize_layer_common` 的「1. 把跨圈累积回填到 view」段，加一句合并：

**查找**（`_finalize_layer_common` 内）：

```python
        # ---- 1. 把跨圈累积回填到 view ----
        view.roles_run = list(state.get("roles_hist") or [])
```

**替换为**：

```python
        # ---- 1. 把跨圈累积回填到 view ----
        # [P1-6 补] 把中间圈的 errors 合并进来（最终 view 只有最后一圈的）
        _cross_errors = list(state.get("all_view_errors") or [])
        if _cross_errors:
            _existing = set(view.errors or [])
            for _err in _cross_errors:
                if _err not in _existing:
                    view.errors.append(_err)
                    _existing.add(_err)
        view.roles_run = list(state.get("roles_hist") or [])
```

### 第四步：B/C/D-H 通道对齐

`_b_finalize_layer` 走的是同一份 `_finalize_layer_common`，但它的 state 来自 `_b_state[entry]`，需要同样加 `all_view_errors` 字段，并在 `_run_one_round_B` 里逐圈收集。

在 `_run_one_round_B` 里，`view = dg.run(inp)` 之后加收集：

**查找**（`_run_one_round_B` 内）：

**替换为**：
