## 修改二：`view.errors` 跨圈累积

**位置**：`MetaDGTF._run_layer` 的圈循环 + `MetaDGTF._finalize_layer_common` 的收尾回填。

**根因**：`_run_layer` 每圈新建 `DGTF` 实例、每圈返回的 `view` 是**该圈独立的对象**，循环结束后只保留最后一个 `view`。中间圈的 `view.errors`（包括 P1-6 写入的「deferral 被拦」）随 view 一起被丢弃。`pool.meta` 跨圈累积，但 `pool.meta` 不进产物。

**改法**：在 `_run_layer` 的圈循环里，每圈结束后把 `view.errors` 收集到一个跨圈列表；在 `_finalize_layer_common` 里把这个列表合并回最终 view。

### 第一步：`_run_layer` 的循环内收集

在 `_run_layer` 方法开头（`view = None` 附近）加一个累积列表：

**查找**（`_run_layer` 内，约在 `view = None` 那一行附近）：

```python
        view = None
        prev_product = ""
```

**替换为**：

```python
        view = None
        prev_product = ""
        # [P1-6 补] 跨圈累积 view.errors —— 每圈新建 view、只 return 最后
        # 一圈，中间圈的 errors（含 deferral 被拦留痕）会随 view 丢弃。
        # 这里逐圈收集，收尾时合并回最终 view。
        _all_view_errors: List[str] = []
```

然后在圈循环里，`view = dg.run(inp)` 之后、`view.rounds_run = layer_no` 附近，加上收集语句：

**查找**（`_run_layer` 内）：

**替换为**：

**替换为**：
