### ★ 最重要的一条：观测式「组间 ≥ 组内」是**结构性不可判定**

`agree13` 同题两跑实测 **0.0 vs 1.0**（组内极差 1.0 > 组间差 0.083）。
根因不是 n 小：**子问题集合每跑重新拆解** ⇒ 「组内变异」里混进了**上游拆解**
的变异。再跑一百次也一样。修法 = **受控实验**（测量学的 test–retest）：
固定 12 条子问题 + 固定外部材料，只让三票重投 8 次。
`_ab_tri_votes_v1233.py`，五臂 = W4 关/开 × 温度 0.0/0.7 + **证据反事实**。

读数（`_v1233_votes.md`）：
- **主判据 F 检验**（= 组间 ≥ 组内的标准 ANOVA 实现）t0 **F = 15.1**（t = 3.89）⇒
  **成立**；t7 F = 1.74 仍 ≥ 1。
- **功能读出**（换掉恒 0 的旧指标）：第 3 票**唱反调率** OFF 0.200 → ON **0.618**；
  **最终判决变化率 29.2%** ⇒ W4 让第三票从橡皮图章变成真的独立裁判。
- **证据反事实**：外部材料换成相反说法 ⇒ 第 3 票 **62.5%** 的条目改判
  ⇒ 它真的在读外部材料（构造性证明）。
- ★ 旧指标「第三票改变多数结论」在 3 票制下**恒为 0**（两人一致时第三人
  永远改不了多数）—— 恒不触发的指标是自欺，已换掉。

### ★ 过程中抓到的真问题：三票判决读**模型返回的 id** 从不校验

受控实验实测某票返回 **0 起** id ⇒ 引擎按 1 起对齐 ⇒ 该票**整票错位一格**，
既不报错也不留痕。同族共 **3+1 处**（审计探针新增的 **L 类**一次扫出）：
① 多票 `_adjudicate_sub_tristate_multi`；② 单票 `_adjudicate_sub_tristate`；
③ `_parse_subs` / `_decompose_from_pool` 的**子问题 id 直接取自模型**；
④ 产物 `votes[].voter` 记的是**位置**，丢一张票就重编号 ⇒ `agree13` 比的是
**别的 prompt 对**。
修法：`_normalize_judgment_ids`（1 起原样 / 0 起 +1 / 越界弃票）+
`_canonical_sub_ids`（按位置重编号）+ `voter` 记真票号 + 池级留痕三类计数。
频度：温度 0.0 **0/72**（生产实参，没触发）；温度 0.7 **2/48** ⇒ 定性为
**潜在的静默失败面**，修它成本极低。

### 教训（写进 skill）

1. ★ **「不可判定」往往是口径错，不是样本少**：组内变异混进上游机制变异的口径，
   跑一万次也不可判定；正解是**受控实验**（固定刺激）。
2. ★ **换口径前先问「这个指标在结构上能不能变」**（3 票制下「改变多数结论」恒 0）。
3. ★ **一类判据 > 一处修复**：id 归一化做成审计判据后**当场又扫出两处**。
4. ★ **判据的锚不能写死会变的东西**：`check_v1232_audit` 把被测文件写成
   `元DGTF-V1.23.2.py` ⇒ 升版后必判红；改为取已加载模块的 `__file__`。
5. ★ **skip 必须放在被 skip 的那段之前**：`--from-capture` 判断放晚了 ⇒
   录播白跑一遍，还差点**覆盖**掉直接驱动来的 5 个 stage。
6. ★ 注入器一次只改自己那一档：`_mk_v1232_smoke_checks` 从
   `def check_v1232_audit` 换到 MARK ⇒ 改**生成器**无效，要改**那一档的注入器**。
7. **方法在哪个类**也要先 grep：`_decompose_*` / `_ask_missing_polarity`
   挂在 `DGTF`（层对象），不在 `MetaDGTF`。

### 验收期又抓到的真问题（v1.23.3 内）

1. ★ **空票被重复计成「越界弃票」**：`_normalize_judgment_ids({}, n)` 对空 dict

   被数两次，留痕印「1/3 票可用（空票 1；越界弃票 1）」，**可用票数少数一张**。
   被 **8 个月前写的 `L4.2` 判据**当场拦住（判据的价值实证）。
2. ★ **判据的锚写死版本名**：`check_v1232_audit` 把被测文件写成
   `元DGTF-V1.23.2.py` ⇒ 升版后 C2 必判红。改为取已加载模块的 `__file__`。
3. ★ **`P2.4.b` 的分母只有 0~2**：`und_from/log_total ≤ 0.5` 在 n=1 时不可判定
   （Wilson 上界 0.79），一次**正常的** und→partial 就把它打到 1.0。
   改为「分母 <3 不判红 + 绝对条数 ≤2 兜底 + 判据自带自检负对照」。
4. ★ **负对照批覆盖了主批的 json**：`_run_v1233_triage.py` 两种模式共用

5. ★ **skip 判断放晚了**：`--from-capture` 只在 `by_stage` 构造处判 ⇒ 录播被

## v1.23.4 · 运行期三项总控（联网 / 思考 / 强度）

需求：给联网、思考模式、思考强度做**总开关 + 可选项**，并在交互时由用户选。

### 形态
- 顶层新增 `runtime: {web, thinking, effort}`，默认三项全 `auto`
  = **不覆盖任何既有键** ⇒ 与 v1.23.3 行为**逐字相同**（判据：配置 JSON 逐字相等）。
- `auto` 的语义是「按配置文件」，**不是**「跟上次一样」。
- 两条入口：交互 `_ask_runtime`（回车=auto）+ CLI `--web/--thinking/--effort`；
  命令行 > yaml `runtime:` 段 > yaml 各处既有键。
- 产物多挂 `_runtime`（requested + 生效值），交互与 CLI 横幅共用 `_runtime_summary_line`。

### 关键设计点（都是「不做就会静默出错」）
1. ★ **思考总开关必须连 `api.thinking.stages` 整表一起改** —— `LLM.call` 的
   优先级是「显式 > stage > default」，只改 default 会被 stage 表盖住
   （出厂有 8 个环节是 enabled）⇒ 总开关成空话。变异体 M2 专钉这条。
2. ★ `effort` 只有在**思考开启**时才进 `extra_body` ⇒ 「思考关 + 设了强度」
   是完全无效组合，必须**当场提示**。
3. ★ `_apply_runtime` 是**纯函数**（深拷后改，绝不改入参）—— 交互里若就地改 cfg，
   第二轮选 `auto` 会读到第一轮改过的值，「auto」退化成「跟上次一样」。
   交互在**深拷副本 `run_cfg`** 上应用。
4. ★ `load_config` **套外层**（原名体改 `_load_config_raw`）：它有**四个** return
   出口，插中间就要改四处、漏一处没有判据看得见。
5. ★ `effort` 取值集是 **low / high / max**（不是我第一版拍的 medium）——
   权威来源就在出厂 `dgtf_config.yaml` 的 `api.thinking` 注释里（2026-10-02 实测）。
6. ★ `_runtime.requested` 记**归一后**的请求值（非法输入由 `⚠️` 留痕报告）——
   保证「`runtime` 段三值恒在合法集合内」这条可断言的不变式。

### 本轮踩的坑（写进 skill）
1. 改名 `load_config` 时把函数体第一行 `cfg = json.loads(json.dumps(DEFAULT_CONFIG))`
   **一起吃掉** ⇒ `_deep_merge(cfg, ...)` UnboundLocalError。
   **改名只能换 `def` 那行，不能连着函数体的第一行一起 match。**
2. 注入器里锚点含双引号时写 `\"`，被**三层字符串吃掉一层反斜杠** ⇒ 生成物引号裸奔、
   整文件 SyntaxError。**一律用 `chr(34)` 拼**；并给注入器加
   `ast.parse(NEW_CHECK)` 自检（这条自检当场拦下了第 3 条）。
3. 注入器注释里写了「三个单引号」字面量，把外层 `'''...'''` **提前闭合**。
4. `_normalize_runtime_effort("")` 返回 None ⇒ 交互里「回车=auto」被当非法**反复重问**；
   CLI/yaml 都走默认值，**只有真跑交互能暴露**。
5. 冒烟 `SRC` 还指着 v1.23.3 ⇒ 全套冒烟**假绿**（181 ✓ 却根本没测到新代码）。
6. ★ `phase_v1233` 的「V1 版本一致」**把版本号写死**成 `"1.23.3"`
   ⇒ `--phase all` 跑 v1.23.4 时**旧档必然判红**（纯噪声、看起来像回归）。
   修法：抽 `_version_consistent(mod, src)`，版本号**从被验文件名推导**
   （比写死更强：多钉了「文件名与 __version__ 不许脱节」）。
