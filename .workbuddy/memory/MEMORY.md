## 形态与红线
- 单文件 `元DGTF-V1.2X.N.py`（v1.23.4 = 23134 行，**纯 CRLF**，无包 / 无测试框架 / **无 git**）。
  四层 0/1/both/all × 螺旋跑圈；三通道 content/context/self。
- 红线：输入是**形状**不是数据；悬置不打分；未对齐合法；停止与清算分开；
  失败留痕；入池前挡重复；参数按层可覆盖；自省是**另一个视角**，不可合并。

## 写文件铁律（主文件纯 CRLF）
- 禁用 `sed -i` / `awk` / Write 直改 → 走补丁脚本：read_bytes → 断言
  `CRLF数 == LF数` → 转 LF → 替换 → 转回 CRLF → **write_bytes**
  （★ write_text 会产出 `\r\r\n` 且**不报错**）。写完自检 `\r\r\n` 计数为 0。
- 替换前断言锚点出现次数 == 1；锚点必须**整行且带开括号**（`def name(`），
  否则会被**前缀同名**函数 / 缩进不同的同名注释**子串命中**。
- 断言用字面串不用正则；含引号的锚点 `chr(34)` 拼；反斜杠 `chr(92)` 拼。
- 改主文件一律走 `.py` 脚本文件，**不用 heredoc 内联**（会吃掉一层转义）。
- docstring 不写单反斜杠；抠 docstring 先转 LF + `textwrap.dedent`，中文显式 utf-8。

## 判据 / 验收通则（最高频事故源）
- **判据随实现更新**：旧判据翻红先分清「真回归」还是「判据过时」。修法是
  改到新语义，不是放宽判据。反过来，老判据也会抓出新改动的真错。
- **锚不能是会变的东西**：版本号从**文件名推导**（不写死），比率不写 n=1，
  读外部产物用**内容特征**定位（不用 mtime / 排序），会随时间缩小的集合
  **冻结成时点快照**。取产物取**最新**（`st_mtime`），不取 `sorted()[0]`。
- **判据要落在行为上**，不是「命名说通」。锚要对准**实现本体**（主路径，
  不是兜底路径）。**审计必须自带变异体** —— 没变异体的「全绿」只说明没跑。
- **变异体要打在判据读的那个东西上**（改前缀名不算，要 `if X:` → `if False:`）；
  负对照样例要落在被变异体的那个条件上；负对照批不共用输出文件。
- **方向错的断言比没断言更危险**（`>=` 写成 `==` 才抓得住「一直在加」）。
  幂等自检零成本：备份 → 连跑两轮 → `cmp` 逐字节。
- **能力存在性用构造性证明，效果大小才用采样**。**一类判据 > 一处修复**。
- 零触发 ≠ 没用（做负对照）；只升不降的指标是自欺；宣称「稳」前查是否被下游
  clamp 压出来；同条件重复 ≥3。
- 两臂对照前先证**两臂都真产出了这个量**（`"k" in obj`，非 `.get(k)`），
  且两条路径产的是**同一把尺子**。「检测缺省」的代码要在**补默认值之前**判。
- 「N 个来源投票」必须报**可用来源数**（空 dict 合法 = 第三类失败）。
- 登记类判据**两向对账**（未登记判红 + 过期登记判红）。

## 常见错型速查
- 同一条逻辑两条实现（serial vs 并行）已多次出现 → 查重复 **grep 形态**。
- dict 字面量**重复键静默覆盖**；搬运 `dict(x)` 静默吞新字段；
  局部变量与模块级函数**同名** = UnboundLocalError 定时炸弹。
- 搬运函数正文**用 AST 行号切片**，别手抄（141 行必错）。
- 抠函数体 / 抠 docstring 的失败是**静默的**，只能靠对表发现。
- 同一件事的标记串**日志侧 ≠ 产物侧**，判据两端分别 grep。
- 改名只能换 `def` 那行，不能连函数体第一行一起 match。
- 给多出口函数加统一后处理 → **套外层**，不插中间。
- 写枚举 / 参数取值集前先**在本仓库找权威来源**（yaml 注释 = 上一轮实验记录，
  优先于我的先验）。
- 总开关要把**整条优先级链**列出来逐层覆盖（会被 `stages` 表盖住）。
- 交互里每轮可改的选项作用在**副本**上（纯函数不是洁癖，是语义）。
- 重构搬函数 → 「按函数体取区域」的判据成批失效，搬前先 grep。
- 「有接线」≠「这跑走得到」，要测就直接驱动方法本身（先 grep 在哪个类）。
- 改别档判据要改**那一档的注入器**。
- 清理不是判据：`finally` 里 `unlink` 一律 `except OSError: pass`。
- 本机 sandbox 的 `>` 重定向**不可靠**（偶发写空/写旧）→ 脚本自己
  write_bytes + `json.loads` 校验非空。

## 测量学 / 成本
- `deepseek-flash` 输出单价是输入 4 倍 → 省钱先压**输出**；非高峰半价。
  一次四层跑实测 ~269 calls / ¥4.17 / 65 min。
- 跑批多 run 并行（`_run_parallel_batch.py --max-concurrency N`）是默认；
  后台长跑**别在命令末尾加 `&`**（会成孤儿）。
- **三态判决一致率天花板**：全项目实测 17~67%，未达当初预设的 80% 线；
  已定性为**标签可定义性边界**，不是工程质量问题（见 v1233 报告 §7.13）。
  读数当「分母有多稳」的参考，不当不合格判词。
