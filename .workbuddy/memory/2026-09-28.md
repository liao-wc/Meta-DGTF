## 四份真实产物的对比分析（用户要求）

产物：21:23 人有灵魂吗(A,12圈,342次调用) / 22:06 P=NP(B,4圈,171次) / 22:31 P=NP(串行,4圈) / 22:50 P=PN(B,4圈,168次)。
注意 22:50 的问题串是 **P=PN**（PN 非标准复杂度类，疑似笔误），不是 P=NP。

**已定位的机制缺陷（有量化证据）**：
1. **B 模式 self 通道被 all 层独占**。self 段层属分布实测：B 两份 = {'元':4}，串行/A 两份 = 四层各 1。
   根因：`_run_one_round_B`(L7037) **每圈**写 self_text，`_run_layer`(L6650) 是**层末**写一次；
   `_merge_self_text` 全局 `blocks[-keep:]`（keep=self_layers=4），B 模式 16 条截 4，
   all 层有 extra_rounds 最后完成 → 最后 4 条全归 all 层。
   后果：self_memory 只剩一个声部 → 展开同质化 → 原地打转（22:06 那份自省自认「9-15 属补写凑数」）。
2. **可判定性在 B 模式下系统性偏 decidable**。同为 P=NP：B 两份判 decidable，串行判 undecidable。
   B 模式第 1 圈四层同时起跑，判据退化成「P、NP 有形式定义」这类表层事实。
   → **B 模式的覆盖率数字不可信**（22:50 那份 1.00）。
3. **极性裁决整体失效**：三份里极性 1 几乎不出现（0/0/1 条），both 占绝对多数。
   22:06 自省原话：「每条 both 只拒绝合并，不判定了什么」。
4. **`_self_check` 是旁观者不是控制器**：三份自省都精准抓到「凑数」「ing 复述:True」「可疑&全6条」，
   但结论只写进 md，不回流到停止判据/重跑/seeds。白烧一次 LLM 调用。
5. 无输入健全性检查：P=PN 全程未被质疑，跑了 168 次调用才停在「PN 读法未定」。

**质量排序（有效对照 22:06 B vs 22:31 串行，同问题同圈数）**：串行胜出，机制性而非偶然
（新概念更多、交叉联结更强、唯一出现极性 1、裁决理由更实）。
人有灵魂吗(A,12圈) 的 all 层「带外承重的闭合」是四份中最好的元层表述。

**建议优先级**：P0 修 `_merge_self_text` 按层轮转 / 可判定性判定串行化到 0 层之后；
P1 极性 both 配额 + 自省回流 + 输入自检；P2 默认改回 serial，补一次 A 模式 P=NP 4 圈补齐对照。
