# v1.23.20 报告 · 留痕从 verbose 拆出独立开关（运行时只留进度）

- **版本**：`元DGTF-V1.23.20.py`（相对 v1.23.19）
- **主题**：把「全量留痕」从 `verbose` 里拆出来，单列 `output.dump_rounds`（**默认关**）；
  同时把出厂 yaml 的 `show_ing` / `show_manifest` 改回注释里本来就推荐的 `false`。
- **一句话结论**：**进度与留痕第一次能分开** —— 想看进度不必再忍受满屏留痕；
  产物零变化，留痕内容在产物 md 的「全量字段」附录里本来就有副本。

## 结论速览

| 项 | 改前 | 改后 |
|---|---|---|
| 留痕（dump_round / dump_final）的闸 | 只听 `verbose` | `verbose and dump_rounds`（**新键默认 false**） |
| ing / view 全文框 | yaml `show_ing/show_manifest: true` | 改回 `false`（`DEFAULT_CONFIG` 本来就是 false） |
| 每圈进度条 `━━━ 层 · 第 N/M 圈` | 听 `verbose` | **不变**（仍听 `verbose`） |
| 产物 md / packed.json | — | **一字不变**（只动了 stdout 守卫） |

## 逐项

### 1. 留痕独立开关
- `DGTF.__init__` 新增 `self.dump_rounds = config["output"].get("dump_rounds", False)`
- `dump_round` / `dump_final` 守卫：`if not self.verbose:` → `if not (self.verbose and self.dump_rounds):`
- `DEFAULT_CONFIG.output` 新增 `"dump_rounds": False`

### 2. 出厂 yaml 回默认
- `output.show_ing: true → false`
- `output.show_manifest: true → false`
- 新增 `output.dump_rounds: false`
- 头部版本 → v1.23.20

### 3. changelog

## 经验教训

1. **「共用闸」拆分要连判据一起拆**：留痕原与进度共用 `verbose`；拆出
   `dump_rounds` 后，冒烟里 **5 处**「手动开 verbose 以测留痕」的 check 立刻红。
   这不是回归，是**判据过时** —— 给它们补 `dump_rounds = True` 即可。
2. **改默认值要连「登记表」一起销账**：`CONFIG_TUNED` 记的是「yaml 偏离默认的
   手调项」；把 `show_ing/show_manifest` 改回默认后必须删条目，否则
   `check_config_parses` 判「登记表过期」。
3. **锚点是子串时会被注释命中**：yaml 注释里有 `#     show_ing: true`，
   以 `  show_ing: true`（2 空格缩进）做锚点会命中 **2 次**；加换行前缀才唯一。
