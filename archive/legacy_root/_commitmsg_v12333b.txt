二、五条前沿依据（逐条对应一处落地）
  ① 重述失真毁下游链 —— BenchDrift (arXiv:2608.11694)：「含义保持的重述」使答案
     **双向漂移**，且**强模型损失远大于收益**；Revisiting Reliability
     (arXiv:2512.14754)：同意图换措辞 ⇒ 指令跟随**最多掉 61.8%**。→ 锚点保真度。
  ② 对撞是否真发生 —— SIEV (arXiv:2510.18134)：核心指标 = **对抗性依从率**；
     「过于胆怯」的模型 pS 高但推理深度低 = **假对撞**。→ 阴阳分歧度。
  ③ 早期信号提前停 —— RASC (NAACL 2025) 省 ~70% 采样；DeepConf (ICLR 2026) 省
     **84.7% token**（★ **全局平均会掩盖局部塌陷**）；Think@n 成本 **−49%**。
     → **依据储备**（未接主循环）。
  ④ 语义密度 / 信息瓶颈 —— 提示压缩率 `R = I(X;Y)/H(X) > 0.6` 为优；
     **超过 5 个无信息 token ⇒ 性能降 15%+**。→ 语义密度。
  ⑤ 降本叠加顺序 —— Tokonomics 2025：单策略 30~50%、**叠加达 85%**；顺序 =
     批处理 → Prompt 缓存（**静态在前动态在后**）→ 模型路由 → 提示压缩 →
     输出长度控制 → 语义缓存。

四、落地四项（统一规格：纯函数 + 零成本 + 可开关 + 有留痕）
  L1 **激活阴阳合并**（opt-in `merge_expand`，默认 **false** ⇒ 零行为差）：
     `_expand_pair` 内 `len(jobs)==2 and _action_on(cfg,"merge_expand",False)`
     ⇒ 走 `_expand_pair_merged_once`；不可用则回落两臂独立调用并**打印留痕**。
  L2 **`yin_yang_divergence(yin, yang)`**：`1 - max_i max_j sim`（`_overlap_coef`
     + `_similar` 两把尺子取大）；`< 0.30 ⇒ "fake_duel"`；任一侧空 ⇒
     `divergence=None` + `verdict=""`（不表态）。
  L3 **`restate_fidelity(question, anchor)`**：`coverage`（问句关键词被锚点覆盖比）
     / `ratio`（长度比）；`coverage<0.20 ⇒ drifted`、`ratio<0.35 ⇒ thin`；
     任一空 ⇒ 全 `None` + `""`。
  L4 **`semantic_density(text)`**：分子 = 扣**填充语**（的/了/是/在/和/与/或/及…
     …综上所述…）+ **标点**（`unicodedata.category` 首字母 ∈ P/S）后的字符数；
     分母 = 全字符数；空输入 ⇒ `None`；**纯字符统计，零 LLM 调用**。
  · 出口 `View.quant_readings: Dict[str, dict]` + `to_dict`（**有才出**）；
    唯一写入口 `_quant_note(view, key, val)`（值不可用就**不写键** ⇒
    「没测」与「测出来是 0」**必须区分**）。
  · 三处**真实入口**接线：ing 输出后（`semantic_density(view.collision)`，<0.6 告警）
    / 锚点确定后（`restate_fidelity(_q0, str(view.anchor))`，drifted 告警）/
    `_expand` 调用后（`yin_yang_divergence`，fake_duel 告警）。
