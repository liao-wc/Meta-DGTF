二、五条前沿依据（逐条对应一处落地）
  ① 重述失真毁下游链 — BenchDrift (arXiv:2608.11694)：含义保持的重述使答案
     **双向漂移**，「强模型损失远大于收益」；Revisiting Reliability
     (arXiv:2512.14754)：同意图换措辞 ⇒ 跟随率**最多掉 61.8%** → 锚点保真度。
  ② 对撞是否真发生 — SIEV (arXiv:2510.18134)：核心指标 = **对抗性依从率**；
     「胆怯」模型 pS 高但推理深度低 = **假对撞** → 阴阳分歧度。
  ③ 早期信号提前停 — RASC (NAACL 2025) 省 ~70% 采样；DeepConf (ICLR 2026) 省
     **84.7% token**（★ 全局平均会掩盖局部塌陷）；Think@n 成本 −49%
     → **依据储备**（未接主循环）。
  ④ 语义密度 / 信息瓶颈 — 提示压缩率 R = I(X;Y)/H(X) > 0.6 为优；
     **超过 5 个无信息 token ⇒ 性能降 15%+** → 语义密度。
  ⑤ 降本叠加顺序 — Tokonomics 2025：单策略 30~50%、**叠加达 85%**；
     批处理 → Prompt 缓存（静态在前动态在后）→ 模型路由 → 提示压缩 → 输出控长 → 语义缓存。
