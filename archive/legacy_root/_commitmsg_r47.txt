fix(dgtf_app): R47 修用户三图 —— 点开没内容 / 下方大面板 / 乱读文件

用户给了三张截图，一次报了三件事。逐条对账：

【A 点开导入的文件没显示内容（not found）】
根因：library.py 的 read_local() 查找链**漏了 ANCHORS_DIR**（导入落盘目录），
只查了 PROJECT_ROOT / docs ⇒ 任何导入的资料点开必 not found。

【C 顺手发现的安全洞：read_local() 能读任意文件】
把「黑名单」思路翻成**白名单**，三层防御：
  ① 点开头文件名（.env / .netrc / .gitignore）一律不读
  ② 无扩展名（.env 就是这一类）不读
  ③ 只读文本类扩展名白名单，且落盘前**再挡一次**

★★ 清掉同一颗雷的**三个位置**（最贵的一处）：
     return None                       # ← 函数到此结束
     # ★ 富格式文件：原名存的是        ← 以下不可达
     return (ANCHORS_DIR / base).read_text(...)   # 裸读，**绕过白名单**
  这段不可达代码今天无害，但只要有人删掉那个「看似多余的 return None」
  （很自然的动作），任意文件读立刻复活。
  最后一处藏在 `_safe_read()` 里，而且引用了 read_local 的局部变量 `base`
  （_safe_read 里根本没定义）⇒ 真被放出来会直接 NameError
  （这也反证它从没被执行过）。上一版补丁是「**追加**而非**替换**」才留下它。

【B 改成「回形针旁小窗 + 图标格 + 常显 ×」】
· 形态：输入框下方的整行列表（ap-row）→ 小窗里的方形图标格（ap-tile），
  图标按扩展名给字形（零依赖），标签过长保留头尾（用户这批文件名前缀
  高度相同，纯 CSS ellipsis 会全长得一样、分不出谁是谁）。
· 角标 × **必须常显**：第一版做成悬停才显（opacity:0）⇒ 截图里整个 ×
  都看不见 = 等于没实现这条需求。改成 opacity:1。
· ★★ 定位三轮实拍才定下来 —— 用户原话「在其右边」**字面执行会失败**：
    贴输入框上沿  → 压住欢迎语
    贴 .composer 内缘 → 落进输入框、压住功能胶囊
    贴 .composer 外缘 → 1600 视口溢出 36px
