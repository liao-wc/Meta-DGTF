## 5. 已知边界（如实冻结）

| 边界 | 状态 |
|---|---|
| 0.5B 语义能力 | 层 1/both/all 的「达成」唯一主瓶颈；结构门只保证 JSON 形状，不保证语义 |
| 结构门对契约不符 stage | 只会「失败得更快」；真正修法是 local 直连（V2.2.16 已做） |
| 层1/both 圈内判据 | flat 需 3 个逐圈点，默认 rounds=2 只有 2 点 ⇒ 「判据样本不足」是结构边界（见审计报告 §4/§7） |
| 元层圈内 crystallize | 停止判据圈内结构不可达；本版不改行为（需云端 A/B 预算） |
| 本地档定位 | 零成本链路验证 / 离线可用，不是生产质量档 |
| 云端质量档 | 本阶段零 API 成本，未复跑 |
