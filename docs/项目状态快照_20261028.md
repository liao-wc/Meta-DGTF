## 4. 已知边界（如实冻结）

| 边界 | 状态 |
|---|---|
| 0.5B 结构化输出能力 | 主瓶颈：json_repair 类调用多（多为 LRU 缓存命中）、ing/view 会撞 224 token 上限 ⇒ 层1/both/all 的「达成」需更强模型或更长本地适配训练 |
| 层1/both 圈内判据 | flat 判据需 3 个逐圈点，默认 rounds=2 只有 2 点 ⇒ 「判据样本不足」是结构边界，不是失败（`docs/四层目标读数审计_20261028.md` §4） |
| 元层圈内 crystallize | 停止判据 `crystallize>=1.0` 在圈内结构不可达（closure 收尾才赋值），本版不改行为（需云端 A/B 预算） |
| both 分母口径 | 代码用上游层数（恒 2），docstring 写层面数；判定为「代码行为有意」，只修 docstring，主读数语义不动 |
| 本地档定位 | 零 API 成本链路验证 / 离线可用，不是生产质量档 |
| 云端质量档 | 本阶段未花 API 预算；道生专属模式 e2e 数字沿用 10-27 快照 |
