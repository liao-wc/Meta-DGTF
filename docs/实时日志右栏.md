# DSH 工作台右栏 · 实时运行日志

## 用法

1. 右侧栏点 **浏览器**（Browser tab）。
2. 地址填：http://127.0.0.1:8770
3. 面板自动选择最近写入的日志文件，1.2s 轮询，跟随最新输出。

## 为什么不是直接改 DSH

DSH 工作台右栏是宿主 UI（Cordis client plugin），工作区源码不能直接改。
这里用右栏内置 Browser tab + 本机 loopback 页面实现同样效果，不改宿主。

## 文件

- dgtf_livelog.py：本地只读日志面板；绑定 127.0.0.1；默认跟随
  _ab_*.log / _gate_*.log / dgtf_app/runs/*.log；只读 workspace。
- _run_live.py：把命令 stdout/stderr 实时 tee 到日志文件；
  普通 _run_gate 会等进程结束才落盘，实时面板看不到，故后台真跑用 _run_live。

## 启动

    python dgtf_livelog.py --port 8770

## 运行一个可实时看的任务

    python _run_live.py _ab_allv2_q2b_live.log -- python 元DGTF-V1.25.0.py -c configs/方案I-AllV2-pilot.yaml --parallel serial "问题"

面板会把 _ab_allv2_q2b_live.log 作为最新文件自动选中。

## 新决策块与标签（v1.26 · 统一决策与证据闭环）

右栏只负责**看实时进度**；四个新决策块不靠右栏做解析。它们的中文标签以
`dgtf_app/params.py` 的 `DISPLAY_BLOCK_CN` 为准（与工作台 `/api/params` 下发的
`display_blocks` 同源，改一处即可）：

| 块 | 中文标签 | 在哪看 |
|---|---|---|
| `decision_trace` | 统一决策回执 | 跑完后的产物 md「## 结论摘要」+ `packed.decision_trace` |
| `fact_flow` | 事实流 | 确定性模块读数；开关 `auto.fact_flow.rounds_max` 只管圈数（四层不砍），明细接入后随产物落盘 |
| `evidence` | 证据链 | 同上 |
| `unified_eml` | 统一 EML 记忆 | 产物 md「本次记忆（EML 经验回路）」+ packed |

### 右栏日志里会看到 / 不会看到

- 会看到：`【0】修行 DGTF…` 四层层 banner、圈标、token 读数、停止行 —— 看进度够用；
- 不会看到：结论摘要、事实流 / 证据链 / 统一 EML 的明细。引擎自 v1.23.20 起把
  「全量留痕 / ing·view 全文」默认关掉，右栏只有进度；明细请跑完看
  `outputs/<产物>.md` 或 packed JSON。

### 缺读数一律「未测」

- 新块未接入 / 本次没触发时，展示层写「未测」，不写 0（0 会被当成「测了且为零」）；
- `decision_trace` 带 `error` 字段 = 该跑次没生成回执（引擎只告警、不阻断）；
- 一致性四态：match（一致）/ mismatch（冲突）/ partial（部分）/ not_comp（不可比）。

### 看 packed 里的决策回执（可选）

    python -c "import json,glob,os; f=max(glob.glob('outputs/*.packed.json'), key=os.path.getmtime); d=json.load(open(f,encoding='utf-8')); print(json.dumps(d.get('decision_trace'), ensure_ascii=False, indent=1))"

若最后一份是旧版引擎产物，打印 `null` —— 换一份 V1.25.0 之后新跑的 packed 即可。

---

## 限制

- 只在本机 loopback；不要暴露公网。
- 只读日志，不控制任务。
- 右栏 Browser 的 sandbox 与 History 由 DSH 管理；刷新页面会重新载入当前文件。
