## 3. 最近合并的优化（Round 140–162）

- **CUDA graph 解码**：单序列（StaticCache）token 一致、约 2x；批量 B=2..4（cache 3072）无长 prompt fallback；
- **dual_judge local**：贪心 temp0 + judge_timeout 90 + 本地预算 4 次，真实 run 4 次接管；引擎本地合批默认开启（失败逐块回退）；
- **服务合批**：`/generate_batch`、请求级合批（0.25s 窗口）、`/metrics` 可观测（`graph_generations`/`batch_graph_generations`/`batch_coalesced`）；
- **self_check local**：贪心 graph 单次 2.1x，但端到端仍 opt-in（本地判定失败回退 LLM 拖慢墙钟）。

## 4. 已知边界（当前冻结）
