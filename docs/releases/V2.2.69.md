# Meta-DGTF 引擎 V2.2.69 发布说明（2026-10-30）

> 类型：PATCH（测试/证据 + 小配置旋钮）。主题：确定性解码开关，层1 可测复现。
> App 2.0.81 不变；零云 API。

## 1. 变更

- 引擎 `api.temperature`（默认 None ⇒ 保持 0.6，零行为差）：
  `LLM.call(... temperature=None)` 时读 `self.temperature_default`，再回落 0.6；
- probe 新增 `--temperature F`：透传 `api.temperature`，用于有界可复现实验；
- meta 记录 temperature。

## 2. 实验结果（零成本，本地 0.5B）

| 配置 | llm_calls | candidates | settle.total | 判定 |
|---|---|---|---|---|
| 默认（temp 0.6） | 27 / 44 / 31 波动 | 0 / 3 / 0 波动 | 0 / 1 / 0 | 不可复现 |
| **temp=0（playbook 默认）** | **42 / 42** | **3 / 3** | **3 / 3** | **可复现（0.0，判据样本不足）** |
| temp=0 + playbook off | — | 0 | 0 | unmeasured（隔离 EML 反而不利） |

⇒ 温度 0.6 是候选/读数不可复现的主因；固定温度后层1 **可测且可复现**。

## 3. 已知限制

- 目标判定仍为「判据样本不足」：引擎停止规则在 2 圈即收（soft_max/fact_flow 提 3 仍只跑 2），
  3 个逐圈点门槛未满足；未硬凑；
- 默认生产温度保持 0.6（零行为差）；`api.temperature: 0.0` 只用于对照实验。
