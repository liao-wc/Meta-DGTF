# Meta-DGTF 引擎 V2.2.39 + App 2.0.64 发布说明（2026-10-29）

> 类型：PATCH。主题：预算紧张时复用未验证产物（省整单）。引擎侧零行为差；零 API 花费。

## 1. 问题

App 产物缓存只复用 verified + answer_ready 的 packed；本环境多数真实产出为
unverified，导致同题重复提交仍整单重跑、重复计费。

## 2. 修法：预算紧张允许同题未验证缓存

- plan.allow_unverified_cache：预算 warn/critical 时 True（dynamic_opt.cache_policy 说明）；
- server._find_cached_pack(allow_unverified=True)：
  - 同题精确匹配可复用 unverified/needs_evidence 产物；
  - 语义回退仍只复用 verified（不放大风险）；
  - 响应带 cache_hit / cache_unverified / cached_from；
  - 显式 no_cache/force_rerun 仍强制重跑。
- apply_plan 透传 allow_unverified_cache。

## 3. 全链路本地验证（零 API 花费）

fused_full_chain 16 → 21 项：新增 D0–D4
- D0 根目录 seed 任务完成（未验证产物）；
- D1 同题再提交（allow_unverified_cache=True）⇒ cache_hit=True；
- D2 cache_unverified=True（seed 非 verified）；
- D3 复用任务迅速 done、继承 seed output_name；
- D4 不生成新 packed（0 次新 LLM 调用）。

单测：test_dynamic_opt 99 → 102（O1 ok=False、O2 warn=True+policy、O3 apply_plan 透传）。
