# App V2.0.29 发布说明

发布日期：2026-10-26

上一版：App 2.0.28

## 主题

产物活动灯改为真实落盘/生成触发。

## 主要改动

- 产物灯不再仅跟随任务运行状态。
- 可交付产物 `.md`、层级 `.json`、`.packed.json` 新增/更新时亮蓝。
- 排除 `.run.json`、`.run.log` 运行元数据，避免启动即误亮。
- 写入后蓝灯保持 5 秒，然后自动熄灭。
- 实测：任务启动阶段不亮，产物生成阶段亮，完成后 5 秒内熄灭。
