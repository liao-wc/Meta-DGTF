## 2. 新增

`scripts/release_preflight.py`：

1. `sync_readme_numbers.py --write` + `sync_snapshot_numbers.py --write`；
2. 两者 `--check` 复核；
3. `release_process_check.py --pre-tag` 发布门预检；
4. git 工作区提醒（只警告不阻塞）；

`--check` 模式只校验不写。退出码 0 = 全部通过。
