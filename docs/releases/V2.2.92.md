# Meta-DGTF 引擎 V2.2.92 发布说明（2026-10-31）

> 类型：PATCH（动态配置）。主题：**opt-in 自动最小圈数（层1 可判定化）**。
> 默认关闭 ⇒ 零行为差；App 2.0.83 不变；零云 API。

## 1. 新增

`spiral.min_rounds_judgeable`（默认 **false**）开启时：

- 目标层（默认 `1`/`both`）计划圈数自动抬到 `min_rounds_judgeable_target`（默认 3）；
- 对应层的 `min_rounds` 同步抬到 target（停止理由不会提前打断）；
- 可用 `min_rounds_judgeable_layers` 自定义层；
- 默认关闭时 `_spiral_for`/各入口行为**逐字不变**。

新增 `dgtf_engine/dgtf_v2/judgeable_rounds.py`（纯函数）+ `tests_judgeable_rounds.py`（10 项）。

## 2. 端到端验证（零 API 本地链）

仅加 `--config-set spiral.min_rounds_judgeable=true`（不再手传 `--rounds 3`/min_rounds）：

| 指标 | 结果 |
|---|---|
| 研究层 rounds_run | **3**（自动抬圈生效） |
| 逐圈 trace | 3 点 |
| 目标判定 | **not_achieved（main=0.0）** |
| llm_calls | 55（本地） |
| probe 断言 | **23/23 PASS** |

## 3. 边界

- 默认不开：开启会让研究/对撞层多跑 1 圈（成本约 ¥0.074/圈/层，按既有校准）；
- 建议只在「quality 档 + 预算 ok + 目标是可判定性」时由 profile/App 显式开启；
- 开启后 main 取值仍会随状态波动（0.0/0.5），但不再「判据样本不足」。
