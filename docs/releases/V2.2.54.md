- 事实来源：docs/app_selftest_latest.json / outputs/_e2e_local/_layer_goals_probe_latest.json /
  docs/v2_tests_latest.json / docs/fast_gate_latest.json / docs/acceptance_latest.json /
  docs/app_version_latest.json / 引擎目录最高版。

## 3. 用法

发包前：python scripts/sync_readme_numbers.py --write
发布门之前：python scripts/sync_readme_numbers.py --check（应 PASS）
