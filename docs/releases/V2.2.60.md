## 1. 可重入

acquire_serial_lock 支持重入：父进程已持锁（环境变量 DGTF_SERIAL_LOCK_HELD）⇒
子进程直接跳过，避免「验收串跑器持锁 → 子判据再取锁」死锁。

## 2. 扩展范围

final_acceptance.py / run_v2_tests.py / app_selftest_gate.py 启动即取同一把 local_chain 锁；
与手动跑 fused_full_chain / probe 等互斥（子判据因环境变量继承而跳过）。
