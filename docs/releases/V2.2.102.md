# Meta-DGTF 引擎 V2.2.102 发布说明（2026-10-31）

> 类型：PATCH（层1 可测性）。主题：**研究层拆解为空时的统一兜底**。
> 仅影响「拆解结果为空」的失败路径；App 2.0.83 不变；零云 API。

## 1. 背景

V2.2.101 全量 probe 出现 case1 **unmeasured**：`subs=0`，且 layer0 candidates/probes/threads/amps
全为 0。根因：当 `zero_view` 为空时走**外部拆解路径** `_decompose_question`，该路径没有兜底；
既有三来源回退只挂在 `_decompose_from_pool`（内部路径）。

## 2. 修复

- 新增 `_fallback_layer1_subs()`：在 `_run_layer`（串行）与 `_b_pre_layer`（并行 B）**统一**兜底；
- 顺序：层0 探针/线头 → `zero_view.candidates` → **原问题本身**（`question_fallback`，source `Q`）；
- `decompose_fallback` 新增 `question_fallback()`（source Q、partial、保守）；
- tests_decompose_fallback 扩到 **12/12**（F12：全空来源用原问题兜底）。

## 3. 验证（零 API 本地链）

- probe case1 隔离复跑两次：**40 calls、valued 0.0**、subs=3 partial（source **P1/T1/C1**）——统一兜底实际命中；
- 两次调用数/读数一致。

## 4. 边界

- 问题本身兜底只是可测性保险，不代表质量；source=Q 可在产物中审计；
- 全空来源仍无法产出真实子问题，属 0.5B 语义能力边界。

## 5. 验收

V2 73/73（1234 checks）；fast_gate 27/27；App selftest；一键验收；e2e 18/18；probe。
