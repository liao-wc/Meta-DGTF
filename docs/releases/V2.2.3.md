# V2.2.3 发布说明（机制层）

日期：2026-10-25
类型：MECHANISM（引擎机制层；**默认零行为差**，全部能力显式 opt-in）
上一版：V2.2.2（保留回滚：`DGTF_APP_ENGINE=dgtf_engine/dgtf_v2/engine/Meta-DGTF-V2.2.2.py`）

## 主题

把两个高成本辅助阶段 `self_check`（自省）与 `dual_judge`（对偶判断）做成
**可替换的机制层**：确定性自省核、自省五档、本地模型端点档、环节级 thinking
预算覆盖、双判判定缓存与结构先验；默认配置与 V2.2.2 **逐字行为一致**
（tests_fine_check 用 stub LLM 做 system+user 字节级比对）。

## 档位与默认值

- `output.self_check_mode`：`llm`（默认，零行为差，**生产唯一推荐**）/ `auto_narr`
  （实验档：全量 A/B 实测 quality 0.9615→0.2632 显著降质，不采纳）/ `local`
  （本地模型端点，失败/低置信/不一致自动回退 LLM；当前 0.5B 适配器质量不足，仅联调）/ 
  `auto`（实验档，不进默认）/ `off`。
- `output.dual_judge_mode`：`llm`（默认）/ `cache`（同题重跑零风险复用）/
  `auto`（cache + 结构先验，opt-in；先验高置信覆盖 23.0%、准确率 87.0%）。
- `output.thinking_stage_overrides`：环节级 thinking 覆盖（默认 `{}`）。
- `api.local_llm`：本地自省端点 `{url,timeout,enabled}`，协议见 registry。

## 验证

- fast_gate：**12 / 12 PASS**（audit70 = 71 PASS / 0 FAIL）。
- V2 tests：**40 / 40 PASS，582 checks**（含 tests_fine_check 48/48）。
- 离线回放（177 packs / 577 views）：auto 静态跳过率 23.7% ⇒ 明确不进默认；
  `unsaid_count` 精确一致 82.8% / ±1 91.9%；双源闸判定相同 94.8%；
  `ing_rephrased` 召回 0.035、`suspicious_candidates` 单圈索引 F1 0.330 ⇒
  **不接管决策字段**（这是 auto_narr/local 仍由 LLM/本地模型出决策的依据）。
- 跨跑双判候选重复率 0.64%（命中时 position 一致率 100%）。

## 已知边界

- 确定性核在语义类决策字段（可疑候选/复述/逃避）召回不足，只做计数、复述率、
  叙述与一致性校验；决策字段在 auto_narr/local 仍由模型给出。
- `auto` 档的运行时可跳过率上界 23.7%（<50% 验收线），保持实验档。
- 前缀缓存优化（静态段前置）已实测机制可行（同 system 二次命中 1024/1269
  tokens，TTL > 8min），但当前 prompt 结构未对齐，登记为下一轮 opt-in 项。

## 回退

无需改代码，配置即可回基线：
`output.self_check_mode="llm"`、`output.dual_judge_mode="llm"`、
`output.thinking_stage_overrides={}`；删除 `dgtf_memory/dual_judge_cache.json`
与 `dgtf_engine/dgtf_v2/engine/dual_judge_prior.json` 即完全回到 V2.2.2 行为。
