# APP V1.5.11 发布说明

## 主题

DSH 对话接管与生产就绪收束。

## 改动

- DSH 完全接管模式：允许项目内源码/文档/配置/测试修改、git add/commit/revert、版本号与 CHANGELOG 迭代。
- DSH 对话逐条事件同步：用户、思考、工具调用/结果、assistant 文本、turn/step 状态增量追加。
- 对话视图：滚动查看不自动滚底；工具/思考默认折叠；折叠状态跨轮询保持；运行时长与历史按钮固定在右上角并自适应。
- 原首屏新对话按钮恢复“回到首屏、随后从输入框发起”的原始行为。
- 服务端静默正常客户端断连，避免 err 日志污染。
- app 版本号与静态资源版本对齐为 1.5.11。

## 验证

- fast_gate：PASS 12 / FAIL 0
- selftest：PASS 371 / FAIL 0
- 依赖链审计：PASS 78 / FAIL 0
- app HTTP：200
- DSH守护：运行中

## 边界

- 终止本轮仅取消当前活动轮次，不丢弃已排队 inbox。
- git push/force、密钥、账户/ACL、不可逆外部操作仍保留人工确认。
- 模型原始思考正文语言由模型决定，UI 标签已中文化。

## 上线安全修复（补充）

- 访问口令不再出现在启动日志/URL 打印；新增 scripts/show_access_url.ps1 供本机人工获取。
- POST 改为先鉴权再读 body；JSON 上限 32MB、资料导入上限 200MB，非法 Content-Length 返回 400。
- 孤儿任务回收增加 app_pid 归属校验，避免多实例互踩。
- Git 自动提交只允许已知源码/文档目录或已跟踪文件，日志/临时文件/口令日志不再可提交。
- 真实任务默认 timeout_s=3600（DGTF_TASK_TIMEOUT_S 可调），防长跑失控。
- app 版本号/静态资源/发布说明统一为 1.5.11。
