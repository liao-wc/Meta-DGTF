# Meta-DGTF 引擎 V2.2.77 / App 2.0.82 发布说明（2026-10-30）

> 类型：PATCH（真 bug 修复）。主题：**App 在线策略 route/rounds 透传被静默降质**。
> 引擎零行为差；App 2.0.82；本次修复由真 API 运行诊断发现。

## 1. 根因

`v2_online.choose()` 返回结构化 `route`（list）与 `rounds`（dict），server 直接写入 opts；
`engine_runner.build_cmd()` 旧实现 `str(v)` 把 Python repr 传给引擎，例如：

- `--route "['0', '1', 'both', 'all']"` → 引擎解析出 `['0'`、`'1'` 等非法入口 ⇒ **四层全跳过**；
- `--rounds "{'0': 2, ...}"` → 圈数段全被忽略。

后果：任务只跑 1 次 call（仅 check_input_sanity），答案靠外部证据拼、质量门 blocked。

## 2. 修复

- `engine_runner.cli_value(key, v)`：list→`0,1,both,all`；dict→`0:2,1:2,...`；空/auto→空串；
- `build_cmd` 统一走 `cli_value`（防御所有结构化 opts）；
- server 应用 `v2_online` 前先转 CLI 规范串；
- `test_dynamic_opt` 新增 D2b/D2c 回归（134/134）。
