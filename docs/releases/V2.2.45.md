# Meta-DGTF 引擎 V2.2.45 + App 2.0.70 发布说明（2026-10-29）

> 类型：PATCH。主题：语义候选索引持久化 + 启动预热。引擎侧零行为差；零 API 花费。

## 1. 问题

V2.2.42 的候选缓存只在进程内；服务重启后首次 build_plan 仍要扫描 300 packed
（约 3s），首任务预判偏慢。

## 2. 修法

- 候选清单落盘 dgtf_memory/semantic_cache_index.json（ts + items，300s 内有效）；
- 进程内缓存失效时优先读磁盘索引（实测恢复 0.01s，120 条候选）；
- App 启动后台线程 warm_semantic_cache：构建索引并批量 embedding（等 8771 就绪，
  最多约 12s；失败不影响主流程）。

- test_dynamic_opt 118 → 121（S3 索引落盘、S4 清空后磁盘恢复 <0.5s、S5 预热结构）；
