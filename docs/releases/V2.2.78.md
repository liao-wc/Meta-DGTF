# Meta-DGTF 引擎 V2.2.78 / App 2.0.83 发布说明（2026-10-30）

> 类型：PATCH（动态配置优化）。主题：tier_advice **kind-aware**。
> 引擎零行为差；App 2.0.83；零云 API。

## 1. 背景

V2.2.49 的 tier_advice 对所有 `verified=0` 题型一律建议 fast；但本会话真 API A/B 发现：

| 题型 | quality | fast | 结论 |
|---|---|---|---|
| reasoning | 69,359 / 124.6s | 66,869 / 67.4s | fast 省 ~3.6% tokens |
| choice | 85,208 / 73.2s | 83,265 / 57.1s | fast 省 ~2.3% tokens |
| project | 63,051 / 184.5s | **74,791** / 59.1s | fast **多 18.6% tokens**（只省墙钟） |

## 2. 变更

- `_TIER_ADVICE_EVIDENCE` 增加 choice/project 实测（真 API，约 ¥0.6）；
- 建议逻辑改为**证据驱动**：只有 `fast.tokens <= quality.tokens` 才建议 fast；
- project 相关题（`_prj=True`）按 project 证据判断，不再被场景模型误判为 reasoning；
- 结果：reasoning/choice → fast；**project → current**（理由写明 fast 更费 tokens）；
- `test_dynamic_opt` 新增 F1–F4（134→138 checks），全 PASS。

## 3. 兼容性

- 只改 advisory 字段（`tier_advice` / `tier_advice_why` / `tier_evidence`），不改变实际 tier 与执行；
- 引擎零行为差；App 2.0.83。
