# Meta-DGTF 引擎 V2.2.22 + App 2.0.47 发布说明（2026-10-29）

> 类型：**PATCH**。主题：融合模式"更优"证明 + 动态最优配置全流程可达。
> 生产文件：dgtf_engine/dgtf_v2/engine/Meta-DGTF-V2.2.22.py + App 2.0.47。

## 1. 问题：动态最优配置有一段"死路径"

- MetaDGTF.run() 早已支持 max_minutes / max_tokens，但 main() 从不传 ⇒ 墙钟/令牌预算只能
  从代码调用（测试/脚本），CLI/App 全链路不可达；
- 因此 dynamic_adjust 的"预算超支降档 fast"在真实任务里无法触发，动态最优配置不完整。

## 2. 修法：预算配置全流程接通

| 层 | 变更 |
|---|---|
| 引擎 CLI | 新增 --max-minutes（float，分钟）/ --max-tokens（int），默认 0=不限 |
| 引擎 main | 把两值传入 meta.run(max_minutes=..., max_tokens=...)，与 run() 既有预算逻辑对齐 |
| App engine_runner | _ARG_SPEC 新增 max_minutes/max_tokens 映射；能力门控 _GATED_FLAGS 增加两 flag（旧引擎不透传） |
| 运行期 | 预算到达 ⇒ 层/波边界 dynamic_adjust 降档 fast（质量下限允许时）；rounds_locked 场景只调 thinking/web、不改圈 |

## 3. "更优"判据（用同题真跑，不拍脑袋）

新增 scripts/local_model/test_fused_optimal.py（24 项，进一键验收 strict）：

- **能力对等**：融合后的道生模式保留标准模式全部能力——质量策略（项目 auto:verified /
  事实 auto:web-retry）、缓存预判、预算守卫、项目背景注入、事实/选项题 web 规则、失败回退；
  同时保留道生能力（preset rounds、M4、预算降级、显式快档）。
- **更优（实测矩阵）**：用 MEASURED_SCENARIOS 同题真跑对比历史 auto 档：
  - 成本档（fast / web+fast）质量差在 ±0.02 内、tokens 省 ≥15%；
  - reasoning / choice / fact 三场景至少 2 个成立；
  - 质量优先档（道生 quality→B）不低于历史 auto 质量（B=1.0 vs auto 0.9465/0.9487/0.9581）。
- **动态配置（引擎真代码）**：直接实例化引擎 MetaDGTF 调 _auto_mode_tick：
  - 锁定轮数场景降档只改 thinking、圈数不动；
  - 未锁定场景降档同时把剩余圈数压到 1；
  - fast 质量代理偏低 ⇒ 升档 B 并恢复 thinking 档。
- **变异体**：删预算 CLI / 忽略 rounds_locked / 丢质量策略字段 ⇒ 对应判据判红。
