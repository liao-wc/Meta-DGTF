## 1. 融合语义（道生 = 标准模式）

`resolve_mode` 现在只有一条主链路：

| 请求 | 解析结果 | 说明 |
|---|---|---|
| `auto`（默认） | **daosheng**（source=auto-fused） | 一律走道生 plan；project_related 只决定是否注入项目背景，不改链路 |
| `standard` | **daosheng**（source=fused-standard） | standard 已并入道生模式，requested 保留原入口 |
| `daosheng` | daosheng | 质量档 |
| `daosheng_fast` | daosheng_fast | 预算快档 |

统一链路：**道生 plan（preset + M4 + 预算守卫 + MODE_CONFIGS 默认参数）→ `--mode` 透传
→ 运行期 `dynamic_adjust`（rounds 锁定语义）→ 产物/回显**。旧 standard 链路只保留为
"道生计划生成失败"时的 fail-open 回退，不再作为默认路径。
