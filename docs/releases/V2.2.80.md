# Meta-DGTF 引擎 V2.2.80 发布说明（2026-10-30）

> 类型：PATCH（质量修复）。主题：证据答案**关键数字锚优先** + 真 API 复验。
> App 2.0.83 不变；本轮消耗约 ¥2.7 云 API（余额 8.49→6.40）。

## 1. 背景（V2.2.79 真 API 复验）

V2.2.79 语言降权后，404 题答案从日文变为**中文泛定义**（不含 404），被质量门判
`数字锚 '404' 未命中答案` ⇒ `answer_ready=False`。即：语言偏好不能牺牲题面锚点。

## 2. 修复（V2.2.80）

- `answer_from_evidence` 选择答案时，先看答案是否含**题面关键数字锚**（如 404/2023）：
  - 有含锚点的候选 ⇒ 优先在含锚点候选里按原分数选；
  - 没有含锚点候选 ⇒ 退回原最高分；
- 语言降权（V2.2.79）保留：同为含锚点候选时，中文证据仍优先；
- 新增回归 `case_answer_key_anchor_preference`；tests_evidence **23/23**。

## 4. 边界（如实）

- 若中文证据都不含题面锚点，为保证质量门通过，可能选到**外语含锚原文**（本复原为英文）；
- 不翻译/不改写证据原文；要同时满足「中文 + 含锚」，需证据源或二次改写设计（后续）。
