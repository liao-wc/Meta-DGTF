# Meta-DGTF 引擎 V2.2.79 发布说明（2026-10-30）

> 类型：PATCH（质量修复）。主题：证据答案**语言匹配**（中文题不再把日文片段当答案）。
> App 2.0.83 不变；本次修复由真 API 诊断发现（V2.2.77 诊断运行答案出现日文）。

## 1. 根因

`dgtf_engine/dgtf_v2/evidence.py::answer_from_evidence` 只按题面相关度/官方性排序，**不看语言**；
HTTP 404 题命中一条日文网页证据（含 `404 Not Found` 字面），其相关度最高被选为事实卡答案，
导致中文题输出日文片段（如「…の404 Not Found はクライアントエラー…」）。

## 2. 修复

- 题面为中文（含汉字、无假名）时，对候选证据做语言匹配：
  - 含 ≥2 个假名（日文片段）⇒ **-0.9 降权**；
  - 含 ≥4 个汉字（中文证据）⇒ **+0.25 加分**；
- 只在 `score > 0`（已与题面相关）时生效，避免破坏 relevance gate（无关证据仍返回空）；
- 日文题不降权日文证据（对称不误伤）；**只改排序，不改写证据原文**。

## 3. 验证

- 新回归 `case_answer_language_preference`：中文题在「官方日文 vs 非官方中文」下选中文；
  顺序无关；日文题仍选日文；
- `tests_evidence`：**22/22 PASS**；
- 原有 relevance gate / 命名 / 日期 / 时效用例全部 PASS（无回归）。

## 4. 边界（如实）

- 本修复是**确定性排序**；真实网页证据若只有日文来源，仍会返回该原文（不编造/不翻译）。
- 真实 API 端到端复验待预算允许时做（当前余额 ¥8.49，fast 档一次约 ¥0.2-1.4）。
