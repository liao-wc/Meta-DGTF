# Meta-DGTF 引擎 V2.2.114 发布说明（2026-10-31）

> 类型：PATCH（门禁增强）。主题：**selftest 门顺带校验启动文案语义**。
> 引擎零行为差；App 2.0.85 不变；零云 API。

## 1. 背景

App 2.0.84 曾声称修正「V2 自动策略冻结文案」，但提交内容未生效；
app_selftest 只跑功能自检，**不校验启动日志语义**，因此门禁没发现。

## 2. 增强

- `app_selftest_gate.py` 在跑完 selftest 后，顺带读取临时 server 启动日志：
  - 找到 `V2 自动策略：…` 行并要求显示「冻结（原因）」或「已选择」；
  - 若退回误导性的「无样本，跳过」⇒ 证据 `startup_msg_ok=false`、门禁判红；
- 不额外起服务、不显著增加耗时。

## 3. 验证

- 本版实测：`startup_msg_ok=true`，msg=`V2 自动策略：冻结（…校准未通过）`；
- App selftest 459/0。
