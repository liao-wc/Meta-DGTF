# Meta-DGTF 引擎 V2.2.117 发布说明（2026-10-31）

> 类型：PATCH（可复现实验能力）。主题：**层间串行实验开关 `spiral.layer_serial`**。
> 默认 false，零行为差；App 2.0.85 不变；零云 API。

## 1. 背景

probe 读数/调用数存在方差：temp0 不消除（§7.30）、服务单请求/批组合确定（§7.31）、
层间并发是假设之一（§7.32）。需要一个**只改调度、不改生成**的实验开关来隔离。

## 2. 新增

- 引擎 A 模式新增 `spiral.layer_serial`（默认 false）：
  - false：保持原有 ThreadPoolExecutor 层间并行（零行为差）；
  - true：顺序执行各层，并在输出打印「层间串行实验模式」。
- 仅用于可复现对照/排障，不建议生产开启（会更慢）。

## 3. 实验结论（如实）

route 0,1 / rounds 1 / temperature=0 / layer_serial=true 连跑两次：

| run | calls | tokens | 失败记录 | 三态多票 |
|---|---|---|---|---|
| 1 | 40 | 50,535 | 1 条 | 无有效票 → 保留原标签 |
| 2 | 44 | 50,481 | 0 条 | 正常 |

⇒ 即使层间串行 + 贪心解码仍不一致；差异与「偶发失败记录 + 三态多票无有效票」同现。
**方差主因是本地链偶发失败触发的分支**，层并发是放大器而非唯一原因。
证据：docs/layer_serial_determinism_20261031.json。
