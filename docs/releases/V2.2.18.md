# Meta-DGTF 引擎 V2.2.18 发布说明（2026-10-28）

> 版本类型：**PATCH**（引擎侧零行为差；把「发版流程」变成可复跑的门）。
> 生产文件：`dgtf_engine/dgtf_v2/engine/Meta-DGTF-V2.2.18.py`（`__version__ = "2.2.18"`）。
> 引擎源码除 __version__/docstring 外与 V2.2.17 **逐字相同**（可 diff 复核）。
> App 2.0.37 不变。

## 1. 问题：流程靠人记，就会漏

README §六「版本迭代规则」与 docs/README「维护约定」列了十几项发版动作：
复制引擎升版本、新增/更新判据、五道门、CHANGELOG/发布说明/收束报告、
README/PROJECT_MAP/Pages 同步、提交 + 三标签……但此前**只有部分被机器执行**：
- App selftest 不在 acceptance 里（靠人手跑）；
- fast_gate / V2 / acceptance **不写证据** ⇒ 无法证明「门是这次跑的」，也无法核对
  README 的「当前版本实测」数字是否漂移；
- 版本一致性散落在 8 处文件（引擎/配置/NAMING/README/PROJECT_MAP/LAYOUT/Pages/文档），
  任一处漏改都没人发现；
- 三标签策略、DSH 闭环、完整性/路径检查没有统一入口。

## 2. 机制：发布流程门（release_process_check.py）

`scripts/release_process_check.py`（三态 PASS / FAIL / **N/A 必须带原因**）：

| 组 | 判据 |
|---|---|
| P1 引擎版本一致性 | 最高版引擎 == App `find_engine()` 选中文件；`__version__` == 配置头 == NAMING == README == PROJECT_MAP == PROJECT_LAYOUT == Pages |
| P2 发布产物 | 根 V<v>-发布报告/收束报告、docs/releases/V<v>.md、CHANGELOG 首段、docs 索引、当日状态快照 |
| P3 App 版本 | app_version_check 通过（或 evidence ok） |
| P4 证据新鲜度 + 数字一致 | fast_gate / v2_tests / app_selftest / acceptance 的 `docs/*_latest.json` 存在、<24h、ok；**README 数字与证据逐项相等**（防文档漂移）；四层 probe 全绿且 provenance=当前引擎 |
| P5 标签 | `V<v>` / `engine-V<v>`（--pre-tag 记 pending）；`app-V<app>` 必须存在（App 未变时指向其发布提交，不移动已发布标签） |
| P6 完整性/路径 | file_integrity_check + verify_project_paths |
| P7 DSH 闭环 | 跑 dsh_loop_check；「生产包早于引擎修复」与「用户 App 实例不可达」归类 **N/A+原因**，其余 FAIL 照旧 |

配套证据出口（本轮新增）：
- `fast_gate.py` → `docs/fast_gate_latest.json`（引擎/版本/检查数/失败项）；
- `scripts/run_v2_tests.py` → `docs/v2_tests_latest.json`（文件/checks/skip）；
- `scripts/final_acceptance.py` → `docs/acceptance_latest.json`（三态计数 + 每步）；
- `scripts/app_selftest_gate.py` → `docs/app_selftest_latest.json`（自起临时 App server 跑
  selftest，**绝不碰用户 8765 实例**；起不来 exit=2=没跑）；
- `release_process_check.py` → `docs/release_process_latest.json`（按 pre/post-tag 两次收口）。

## 5. 边界

- 发布流程门不替代内容质量：它证明「流程动作做了、证据新鲜、数字不漂」，不证明答案正确。
- N/A 不是绿：每条 N/A 必须写原因（如本机无 API 预算未复跑生产档、用户 App 实例不可达）。
- 证据 <24h：长时间不发版的 checkout 上本门会红（这是有意的「证据陈旧即未复跑」）。
