# Meta-DGTF 引擎 V2.2.93 发布说明（2026-10-31）

> 类型：PATCH（动态配置健壮性）。主题：judgeable layers 字符串写法。
> 引擎行为仅在该 opt-in 开启时（默认关）；App 2.0.83 不变；零云 API。

## 1. 问题

`spiral.min_rounds_judgeable_layers` 若写成字符串 `"1,both"`，旧实现按字符迭代得到
`['1', ',', 'b', 'o', 't', 'h']` ⇒ 目标层匹配失败、opt-in 静默失效。

## 2. 修复

- `layers()` 支持字符串（按中英文逗号拆分并去空）；列表写法不变；
- 新增单测 J11/J12（字符串拆分 + 计划抬升生效），tests_judgeable_rounds **12/12**。

## 3. 端到端验证（零 API 本地链，并行 B）

配置 `min_rounds_judgeable_layers: "1,both"` + `--rounds 2 --parallel B`：

- 日志出现 **“B 第 3 圈停止”** ⇒ 研究层实际第 3 圈；
- 63 calls / 75,637 tokens（本地）。
