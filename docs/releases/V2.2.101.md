# Meta-DGTF 引擎 V2.2.101 发布说明（2026-10-31）

> 类型：PATCH（门禁强化）。主题：**快照审计扩展：中心版本号 / 权威指针 / 历史标注**。
> 引擎零行为差；App 2.0.83 不变；零云 API。

## 1. 背景

V2.2.100 新增 snapshot_numbers 后，又发现两类长期漂移：
- `docs/README.md` 曾把**历史快照**（known_boundaries §0）当「为准」来源；
- README/CHANGELOG/配置文件头/App 版本可能与当前引擎版本不一致。

## 2. 新增检查（snapshot_numbers 5 → 12 项）

| 检查 | 判据 |
|---|---|
| readme_current_version | README「当前版本」= 最新引擎版本 |
| changelog_top_version | CHANGELOG 首条含最新版本 |
| config_header_version | dgtf_config.yaml 头部版本一致 |
| app_version_in_snapshot | 快照含当前 App 版本 |
| no_historical_authority | docs/README 不得把 known_boundaries 标为「为准」 |
| docs_readme_current_snapshot | docs/README 引用当前快照文件名 |
| known_boundaries_marked_historical | 历史文件已标注「不再作为当前数字来源」 |
