# Meta-DGTF 引擎 V2.2.105 发布说明（2026-10-31）

> 类型：PATCH（发布工具健壮性）。主题：**preflight 证据健康校验**。
> 引擎零行为差；App 2.0.83 不变；零云 API。

## 1. 背景

V2.2.104 过程中曾把一次**失败**的 fast_gate 证据（26/27）同步进 README；
根因是 preflight 只做「同步」，不校验证据本身是否 PASS。

## 2. 修复

- preflight 新增 `evidence_sanity` 前置检查：
  - fast_gate `passed == total` 且 `failed == 0`；
  - v2_tests `fail == 0`；
  - app_selftest `fail == 0` 且 `pass > 0`；
  - acceptance `failed == 0`；
- 任一不健康 ⇒ **拒绝同步/预检**并退出码 1；
- 健康才执行原有 sync → check → release_process 预检步骤。

## 3. 验证

- 当前证据健康：`PASS evidence_sanity` + 两个 sync + pre-tag 全 PASS；
- 负例由逻辑保证（失败计数非零即拒绝）。
