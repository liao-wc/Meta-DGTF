# Meta-DGTF 引擎 V2.2.118 发布说明（2026-10-31）

> 类型：PATCH（可观测性）。主题：**probe 证据记录本地链偶发失败**。
> 引擎零行为差；App 2.0.85 不变；零云 API。

## 1. 背景

V2.2.117 实验确认方差不完全由层并发引起，而与「偶发失败记录 + 三态多票无有效票」同现；
但 probe 证据此前**不记录**这些信号，无法跨运行统计。

## 2. 新增

- `probe_layer_goals.py` 每个 case 证据新增：
  - `failed_records`：引擎输出「⚠️ N 条失败记录」的 N；
  - `tristate_no_vote`：是否出现「三态多票：无有效票」；
- 仅在证据/日志中记录，**不改变任何断言与判据**（probe 仍 82 项断言）。

## 3. 用途

后续可直接从 `outputs/_e2e_local/_layer_goals_probe_latest.json` 统计失败率与方差的相关性，
再决定是否调超时/重试/降载。
