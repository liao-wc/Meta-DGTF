# App V2.0.84 发布说明（2026-10-31）

> 类型：PATCH（日志语义修正）。引擎 V2.2.111 同发；零云 API。

## 修复

启动日志原先把 V2 自动策略的**安全冻结**误报为「无样本，跳过」。
实际原因是 `_V2_LAYER_QUALITY_VALIDATED=False`（层局部质量校准未通过前禁止自动写策略）。

现区分三种状态：
- `已选择 <候选>`：自动策略正常应用；
- `冻结（原因）`：校准未通过，安全默认不覆盖用户计划；
- `跳过（原因）`：真正无样本/其他不可用原因。

## 影响

- 仅启动日志；策略决策逻辑不变（仍冻结）；
- 便于运维区分「没数据」与「安全冻结」。
