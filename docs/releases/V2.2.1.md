日期：2026-10-24

## 主题

V2.2.0 行为级融合后的补丁迭代：推理题质量门闭环、职责读数口径修正、
质量线索降噪、覆盖率/三态读数补齐，以及 App「DSH 本对话」实时视图与
DSH GUI 当前会话对齐。

## 修复

- 解释型「为什么 / 原因 / 机制」类题归 reasoning，走非事实门（不再误判 fact）。
- 研究层判定审计并入 dgtf_engine/dgtf_v2 池内子问题（此前只审渲染视图）。
- 元层闭环清算在 _totalize_all_pool() 之后刷新（修复 all.standard_ok 假缺口）。
- 判定审计只拦越权断言（decidable 无证据 / undecidable 有证据）；纯数字 token 不再冒充证据命中。
- App 的 DSH 实时视图改为当前会话整段回放 + 增量轮询 + 载入更早（与 DSH GUI 一致）。

## 判据补强

- 职责读数：交付面按层取真实产品（duty_deliver_text）；R 增加问项实词级命中；
  职责下限 0.15（规则命中版 R 校准）；元层按闭合职责判 short。
- 质量线索：candidates_backfilled 收尾复核阈值 0.75、self-check 单源降为留痕；
  polarity_all_same_structural / probe_link_dangling 改 view.meta 留痕（不挂质量旗）。
- 质量读数：coverage 兜底链（coverage_basis：可判定加权 / 重算可回答子问题 /
  不可判定方面覆盖）；tri_alpha 可用时 tri_ratio 不再冒充质量，改报 tri_consistency。
- 新增 dgtf_engine/dgtf_v2/tests_patch_release.py（27 项）。
- 成本优化：新增 scripts/precheck_quality.py（离线复算五道质量门，零 LLM 成本）。
