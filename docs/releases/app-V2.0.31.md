# App V2.0.31 发布说明

发布日期：2026-10-26

上一版：App 2.0.30

## 主题

普通模式与 DSH 模式视图隔离，修复跳串。

## 主要改动

- DSH 模式下不再渲染普通任务视图。
- 普通模式下不再被 DSH 异步轮询覆盖。
- 退出 DSH 时停止 DSH 轮询并立即渲染普通任务。
- 进入 DSH 不再自动附着当前普通任务。
- 两种模式各自保留状态，互不覆盖。
