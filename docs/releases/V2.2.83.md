# Meta-DGTF 引擎 V2.2.83 发布说明（2026-10-30）

> 类型：PATCH（离线质量门预检修复）。主题：预算截断产物不再被误判质量失败。
> 引擎零行为差；App 2.0.83 不变；零云 API。

## 1. 发现

脚本巡检时 `precheck_quality.py`（离线五道质量门重算）在最新真跑上 FAIL：
该跑（1+1 题，764,817 tokens）被预算截断，引擎**故意**写 `answer_ready=False`
（reason=体力耗尽（预算截断），不视为 ready）；而 G5 重算没有这条规则，
把正确的存证判成「存证与重算不一致」。

## 2. 修复

- `_fact_quality` 重算时尊重「体力耗尽（预算截断）」口径：ready 置 False 且理由一致；
- `gate_quality` 遇到预算截断产物判 **N/A**（预算边界，不计质量失败）；
- 正常 verified 产物仍走完整 PASS 判定（5/5），不会被 N/A 掩盖。

## 3. 验证

| 产物 | 结果 |
|---|---|
| 1+1（预算截断） | **PASS 4 / FAIL 0 / N/A 1**（G5 N/A 带原因） |
| HTTP404（正常 verified） | **PASS 5 / FAIL 0 / N/A 0** |
