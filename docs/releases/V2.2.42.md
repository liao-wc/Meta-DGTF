# Meta-DGTF 引擎 V2.2.42 + App 2.0.67 发布说明（2026-10-29）

> 类型：PATCH。主题：语义预判双层缓存（性能）+ 语义标定扩到 3 个近重复问法。
> 引擎侧零行为差；零 API 花费。

## 1. 问题

V2.2.41 的语义预判每次 build_plan 都扫描 300 个 packed 并重算 embedding，
acceptance 中 dynamic_opt 从 2s 涨到 97s，拖慢一键验收与任务创建。

## 2. 修法：双层缓存

- _semantic_candidates：verified 候选清单（path/question/web，最多 200 条）缓存 300s；
- _semantic_cache_probe：按 (question, web) 缓存命中结果 120s；
- 命中时仍只 embed 当前问题 + ≤8 个候选（batch 1 次）；
- 预估收益：同一问题二次预判 0ms；不同问题共享候选清单，避免重复读盘。

## 3. 效果

- test_dynamic_opt 109 → 111 项，整套 97s → 6.5s；
- acceptance dynamic_opt 97s → 6.5s（一键验收总时长同步下降）。
