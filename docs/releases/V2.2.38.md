> 类型：PATCH。主题：余额续航预测（budget_forecast）+ 续航不足自动降级。引擎侧零行为差；零 API 花费。

## 1. 余额续航预测

dynamic_opt.budget_forecast = {
  balance_cny, est_cost_cny, balance_after_cny, safe_runs, reserve_runs, advice
}

- safe_runs = floor(balance / chosen 成本)（用最终动态选择成本，含上下文/缓存折算）；
- reserve_runs 默认 2（budget.reserve_runs，可配）；
- advice = ok / low_reserve；余额未知 ⇒ None（fail-open 不预测）。

## 2. 续航不足自动降级

质量档（quality）且预算守卫 ok，但估算只剩 < reserve_runs 次时：
自动降级 fast 并写明 mode_reason（"余额续航不足…→ 降级 fast 保续航"）。
默认 reserve_runs=2：余额 10 / 估 ¥0.13 时 safe_runs≈76，不降级；reserve_runs 调大才触发。
