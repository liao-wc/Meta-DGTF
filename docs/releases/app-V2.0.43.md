## 主题

修正默认总超时为 1800s，解决“跑得完却被 1200s 截断”的根因。

## 根因证据

- 20261028_193212_a7a5e1 在 1200s 终止时仍在 B 第 8/9 波推进，19:51:23 仍有模型调用。
- 历史 verified 真跑最大墙钟 1427.3s，1200s 上限低于已验证上限。
- 1200s 会截断本可完成的真跑。

- DGTF_TASK_TIMEOUT_S 默认 1200 → 1800 秒。
- DGTF_TASK_STALL_S=600 停滞看门狗保留。
- 显式 timeout_s 优先。
