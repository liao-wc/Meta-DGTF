# Meta-DGTF 引擎 V2.2.90 发布说明（2026-10-31）

> 类型：PATCH（质量/可测量性工程）。主题：**研究层拆解确定性回退**。
> App 2.0.83 不变；零云 API（全部本地链验证）。

## 1. 根因（层1 长期「未测出」的工程原因）

研究层子问题只来自 `_decompose_from_pool` 的 LLM JSON 输出；本地 0.5B 链路
解析失败时**静默返回空列表** ⇒ `pools['1'].sub_questions=[]` ⇒ settlement.total=0
⇒ 层1 永远「未测出」（与圈数无关，§86 实验已证）。

## 2. 修复

- 新增 `dgtf_v2/decompose_fallback.py::fallback_subquestions()`：
  从修行层**探针/悬空线头原文**确定性生成子问题（不调 LLM、不改写知识，保守标 partial）；
- 引擎 `_decompose_from_pool` 在 LLM 解析结果为空时调用回退，日志记 `backfill`；
- 新增 `tests_decompose_fallback.py`（6 项：来源/追溯/保守标签/空输入/limit/线头兜底）。
