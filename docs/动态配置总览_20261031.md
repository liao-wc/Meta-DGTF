# 动态配置与动态依赖总览（2026-10-31 · V2.2.116 / App 2.0.85）

> 目的：把「全链路全流程的动态配置/dl 依赖」压到一页，说明每一层在哪里配置、
> 如何动态调整、被哪些门禁与证据约束。数字以 docs/项目状态快照_20261031.md 为准。

## 1. 配置层级（从静态到动态）

| 层 | 文件/入口 | 作用 |
|---|---|---|
| 主配置 | `dgtf_config.yaml` | 引擎默认 + App 自管段；config_keys 门禁审计陈旧键（presets 24 + main） |
| 预设 | `configs/*.yaml`（24 个） | quality/cost/fast/并行档/方案Q 等组合；App profile 列表可见 |
| CLI | `--route/--rounds/--parallel/--web/--config/...` | 单次运行的显式覆盖 |
| App 计划 | 三体动态计划 / 道生模式 / `_schedule_profiles()` | 依据题型、预算、缓存状态选档与层子集 |
| 运行时自适应 | 引擎内：降档、缓存复用、并行/串行、回退层 | 运行中按失败/迟到/质量证据调整 |

优先级：**CLI/App 显式值 > preset > 主配置默认**；自动策略当前因层质量校准未通过而**冻结**（安全默认）。

## 2. App profile 与选择建议

| 场景 | 建议 | 说明 |
|---|---|---|
| 质量优先、预算 ok | quality 档（或方案F 帕累托最优） | 默认多候选/多圈 |
| 成本优先 | cost/fast 档 | route 子集 + 少圈 |
| 需要层1/both 目标判定 | **方案Q 可判定优先**（显式 opt-in） | 研究/对撞 ≥3 圈；≈¥0.074/圈/层 |
| 余额 <¥8 | App 自动降级 fast 档 | 预算守卫；真跑需人工确认 |

## 3. 预算守卫与降档链（零 API 本阶段）

- 余额 **¥6.40**（<¥8）⇒ App 自动降级 fast 档；本阶段全部验证走本地链（0 元）；
- 真 API 重跑需记录窗口差（docs/budget_ledger_20261026.md）；
- 预算 token/墙钟硬上限、省层收益、质量风险门均在验收中覆盖。

## 4. 动态依赖调整（依据与证据）

- **题型**：fact/choice/project/reasoning 影响 route 与 rounds（题型矩阵）；
- **状态**：本地链 503/超时触发重试与回退（503 四类原因见 local_service_health §5b）；
- **缓存**：语义缓存预判/预判缓存/新鲜度门影响是否复用；
- **并行**：serial 与 parallel B 的对照证据（3 题×2 次）：
  - 热岛 serial 44 calls vs B 55；GDP B 更省（43 vs 48）；水三态 serial settle 5 vs B 1；
  - 结论：**模式优劣随题型变化，无可泛化赢家**；preset Q 保持 serial（分母更稳）；
  - 证据：docs/preset_q_serial_vs_b_20261031.json、docs/preset_q_multi_qa_20261031.json。
