## 一、审计口径

三列命中数：源码 / 日志 / 产物。**日志侧与产物侧的标记串必须分别数** ——
本项目已知的坑是同一件事两侧写法不同（日志 `【螺旋停止】…` vs 产物
`**螺旋停止**：…`），照一侧数另一侧会数出 0，然后被误读成「出口没通」。

判定三档：`可达` / `仅源码` / `需核对`。**「零触发」不等于「没用」**：
要分清 ①条件不可达（真该死）②条件窄但在特定情形成立（留着）
③机制压根没工作（重写）—— 分不开就必须做**负对照**。
