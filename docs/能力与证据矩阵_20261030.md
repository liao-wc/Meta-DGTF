## 5. 层1 可测性（V2.2.99 更新）

| 事实 | 结论 |
|---|---|
| V2.2.90 拆解回退（空输出 → 探针/线头） | 层1 从「未测出」转为「有值」（settle=1/1） |
| V2.2.96 全不可判定 → provisional partial | 覆盖「LLM 有输出但全 undecidable」路径 |
| V2.2.97 candidates 兜底 | 覆盖「拆解空 + 探针/线头全空」路径 |
| 全量 probe 三次（V2.2.97） | **状态稳定 valued（3/3）**，main 0.0/0.0/0.5、calls 33/33/44（随状态波动） |
| opt-in `spiral.min_rounds_judgeable=true` | case1：**可判定 not_achieved**（2/2，59 calls）；both：**可判定 achieved**（2/2，98 calls） |
| 默认关 | 零行为差；开启单次多约 1 圈/层（≈¥0.074/圈/层） |

**判定语义**（防误读）：valued=读数可算、achieved=原语阈值命中、not_achieved=原语未命中、
not_judgeable=样本不足、unmeasured=分母为 0——**均不等于质量结论**；质量看 verified/ready + 人工。
详见 docs/layer1_measurable_probe_20261030.md §7.24。

结论：层1 **可测（默认）且可判定（opt-in，默认关）**；目标「达成」仍需真实质量提升，
非工程可测性问题。证据：docs/layer1_measurable_probe_20261030.md（§7.14–7.18）、
docs/layer1_stable_valued_20261031.json、docs/layer1_auto_judgeable_stable_20261031.json。

## 7. 已知边界/风险（更新至 V2.2.99）

1. **答案语言与锚点两难**：中文题在「中文证据不含题面数字锚」时，为保证质量门通过会选外语含锚原文（本会话实测 404 题选到英文片段，verified/ready True）；不翻译/不改写原文；要双满足需证据源语言偏好或二次改写设计。
2. **层1 可测性**：V2.2.97 后整跑**状态稳定 valued（3/3）**，但 main 取值随状态/缓存波动（0/0/0.5）；opt-in 可判定（默认关，成本 +1 圈/层）；目标达成仍未实现。
3. **choice/project verified=0**：choice 0/6+、project 0/4，均未 verified；tier_advice 已按证据驱动（project→current）。
4. **fact verified 非 100%**：偶发 needs_evidence，历史 packed 已清理无法逐例复核。
5. 8765 用户 App 实例为人工实例，未启动时发版门记 N/A（非回归）。
6. 余额 <¥8 ⇒ 自动降级 fast 档；真实重跑需记录花费。
