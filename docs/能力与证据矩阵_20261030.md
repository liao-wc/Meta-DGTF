## 5. 层1 可测性（已知受限）

| 事实 | 结论 |
|---|---|
| route=1 单跑 | `views.1.candidates=0`（层1 需要上游层0） |
| route=0,1 + GDP 题 | 曾出现 `settle=3`（valued）一次 |
| 同配置复跑 | 均回到 unmeasured（27–40 calls、candidates 0–2） |
| 温度固定 temp=0 | **可复现**（可写 3 连跑 30/30/30 calls、2/2/2 cand、0/0/0 settle） |
| temp=0 + 只读基线 | 可复现（32/32 calls、3/3 cand、0/0 settle） |
| 强制 fusion_full | 仍 unmeasured（34 calls、0 cand） |

结论：**可复现已达成，可测未达成**；不要再靠状态碰运气，需引擎侧确定性可判定性度量设计。
证据：docs/layer1_measurable_probe_20261030.md、审计 §57–§66。
