**C · 零触发机制验证**

这个最复杂。需要设计一道题，让以下机制之一或多项必然触发：
1. `escalate_starve_rounds=2` —— 一个子问题连续 2 圈无进展 + 名下有未清偿债务 → 迁向不可判定

4. `stable_layers 2→3` —— 元层走到"自然安住"

设计：
- 对 1+3：需要一道题，研究层会拆出至少一个子问题，然后连续两圈不碰它（不提它做任何推进），但同时会挂一笔账在它名下。这需要研究层在拆解后立刻挂 deferral 给某个子问题，然后连续 2 圈忽略它。**这个不能靠控制 prompt，只能靠选对题**。
- 对 2：需要一道题在非最后一圈触发"层内空转"判据，同时还有"未深入方向"。这需要：池里已经有一些 untouched 方面，但停止判据已经被触发。可能是已经有足够多的"连续无新 &"。
- 对 4：需要一道题元层能走到至少 3 圈，且每圈悬置决定稳定。

设计思路：**用同一道题跑一次，观察是否有触发**；若无，再考虑分题。

实际上更稳的做法是：**先跑一次标准题，收集触发的次数**，然后**有针对性设计**。但这会花多轮真跑。

```python
        #     它交代了"这条历史张力当时被处理过"。旧口径把它算作"没命中"，
        #     于是 by_id 只反映"当下还活着"的那几条，无法回答"元层一共
        #     交代了几条"。
        #   ★ uncovered 仍只对 active 计：已了结的张力**本来就不该**进
        #     uncovered（它没欠交代）。
        _all_duel_ids = {str(s.get("id", "") or "").strip()
                         for s in _all_duel if s.get("id")}
        _all_duel_ids.discard("")
        by_id = len(_covered_ids & _all_duel_ids)

        uncovered = []
        for s in duel:
            t = str(s.get("target", "")).strip()
            if not t:
                continue
            sid = str(s.get("id", "") or "").strip()
            if sid and sid in _covered_ids:
                continue
            if any(_similar(t, a, thr) for a in adjudicated if a):
                continue
            if any(_similar(t, x, thr) for x in suspended if x):
                continue
            uncovered.append(t)
```

## 任务 C · 零触发机制审计脚本

**这一步不改主文件**。新增独立脚本 `_audit_v64_zero_triggers.py`，只读产物，输出审计报告。

### 设计意图

v1.21.60 遗留清单里有 4 项"零触发机制"从未验证：

1. `escalate_starve_rounds=2` —— 连续 2 圈无进展 + 名下有未清偿债务 → 迁向不可判定
2. `no_push_when_idle=1` —— 停止判据是"层内空转"时不被"未深入方向"推迟
3. `_reopen_closed_debt` —— 迁向 undecidable 后被救回
4. `stable_layers 2→3` —— 元层走到"自然安住"

审计脚本的目标**不是**"跑一次看有没有触发"，而是：**用已有的真跑产物，反过来检查每个机制在那一跑里"离触发差多远"**。这比盲跑一次新题更经济，且能给出"该设计什么样的新题"的具体方向。

### 脚本输入与输出

**输入**：产物 md 路径（默认取 `outputs/` 下最新一份）；或 `--packed path/to/xxx.json`。

**输出**：控制台报告 + 写入 `audit_zero_triggers_<时间戳>.md`。

### 脚本内容

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
_audit_v64_zero_triggers.py

[v1.21.64 C] 零触发机制审计（独立只读脚本，不改主文件）。

目标：用**已有的真跑产物**回答下列问题，而不是靠新跑一次去猜。

  机制一 · escalate_starve_rounds=2
    一个子问题连续 2 圈"没任何进展"（没被回答 / 没挂新账 / 没被清偿
    / 没发生分类变更）+ 名下挂着未清偿债务 → 应迁向 undecidable。
    审计：
      · 每个 sub 的 _starve_rounds 字段（真跑后是否被留痕）
      · 研究层每圈的"无进展"子问题集合（从产物 round_log / engagements
        反推：哪些 sub 在两圈内既不在 engagements、也不在 deferrals、
        也不在 reclassifications/escalations）
      · 判据："最少需要几圈无进展才够" vs "产物里实际连续无进展的最长圈数"

  机制二 · no_push_when_idle=1
    停止判据是"层内空转"（ing 复述 / 自省点名未消化）时，**不应**被
    "未深入方向"推迟。
    审计：
      · 每层 stop_reason 是否含"层内空转"
      · 该层收尾时是否还有"未深入方向"（从 view.untouched 里
        source=judge 的条目反推）
      · 判据：几层触发了"层内空转"？其中几层"还有未深入方向"？
        （后者才是这个机制真正要拦的）

  机制三 · _reopen_closed_debt
    迁向 undecidable 后被救回时，被关的账要重新挂上。
    审计：
      · 池里是否有 deferrals 带 reopened_from 字段
      · 是否有 sub 的 decidability_log 出现 undecidable → dec/partial
      · 判据：有几条 reclass 从 und 转出？转出时是否重新挂账？

  机制四 · stable_layers 2→3
    元层悬置决定连续 3 圈同一批 → 自然安住。
    审计：
      · 元层每条 suspension 的 confirmed_layers 长度
      · 元层实际跑了几圈、stop_reason 是否含"自然安住"
      · 判据：最多连续几圈稳定？离 3 差几圈？
"""
import argparse
import json
import re
import sys
from datetime import datetime
from pathlib import Path


def _read_latest_packed(outdir: Path = Path("outputs")):
    """找一份带 packed JSON 的产物；本脚本主要吃 md 里的结构。"""
    md_files = sorted(outdir.glob("*.md"), key=lambda p: p.stat().st_mtime)
    return md_files[-1] if md_files else None


def _parse_md(md_path: Path) -> dict:
    """从产物 md 里把关键信息抽出来。
    不追求穷尽，只抽审计需要的字段。返回结构：

      {
        "stop_reasons": {"0": "...", "1": "...", "both": "...", "all": "..."},
        "deferred_notes": {"0": [...], "1": [...], ...},
        "uncovered_directions": {"0": n, "1": n, ...},
        "sub_questions": [...],  # 从"研究层"段抽
        "deferrals": [...],      # 从"延迟债务"段抽
        "decidability_log": [...],  # 从池段抽
        "suspensions_meta": {"0": [...], ...},  # 从池段抽
      }
    """
    text = md_path.read_text(encoding="utf-8")
    out = {
        "stop_reasons": {},
        "deferred_notes": {e: [] for e in ("0", "1", "both", "all")},
        "uncovered_directions": {},
        "sub_questions": [],
        "deferrals": [],
        "decidability_log": [],
        "suspensions_meta": {e: [] for e in ("0", "1", "both", "all")},
    }

    # 每层的【螺旋停止】行
    for m in re.finditer(
            r"### (修行|研究|对撞|元)层 `(\w+)`.*?\*\*螺旋停止\*\*：([^\n]+)",
            text, re.S):
        entry = {"修行": "0", "研究": "1", "对撞": "both",
                 "元": "all"}[m.group(1)]
        out["stop_reasons"][entry] = m.group(3).strip()

    # 每层的失败/推迟留痕
    # （"体力耗尽（…未深入方向…推迟…）"）
    for m in re.finditer(
            r"### (修行|研究|对撞|元)层 `(\w+)`.*?"
            r"体力耗尽（([^）]+)）",
            text, re.S):
        entry = {"修行": "0", "研究": "1", "对撞": "both",
                 "元": "all"}[m.group(1)]
        out["deferred_notes"][entry].append(m.group(3).strip())

    # 研究层子问题
    for m in re.finditer(
            r"- 子问题 (\d+) 条：可判定 (\d+) / 不可判定 (\d+)"
            r"（另有 (\d+) 条 partial 等）",
            text):
        out["sub_questions"].append({
            "total": int(m.group(1)),
            "dec": int(m.group(2)),
            "und": int(m.group(3)),
            "partial": int(m.group(4)),
        })

    # deferrals（有 reopened_from 的才关键）
    for m in re.finditer(
            r"- \[\w+\] 子问题(\d+) [^：]*：([^\n]*)"
            r"\n  回访条件：([^\n｜]*)"
            r"(?:｜← 重新挂账（接 (\w+)）)?",
            text):
        out["deferrals"].append({
            "sub_id": int(m.group(1)),
            "reopened_from": m.group(4) or None,
        })

    # decidability_log（池段）
    for m in re.finditer(
            r"L(\d+) 子问题\[(\d+)\] 不可判定→(可判定|部分可判定)",
            text):
        out["decidability_log"].append({
            "layer": int(m.group(1)),
            "sub_id": int(m.group(2)),
            "to": m.group(3),
        })

    return out


def _audit_mechanism_1(d):
    """机制一：escalate_starve_rounds=2 —— 连续无进展是否够。"""
    lines = []
    lines.append("### 机制一 · escalate_starve_rounds=2\n")
    lines.append("**判据**：一个子问题连续 2 圈无任何进展（没被回答 / "
                 "没挂新账 / 没被清偿 / 没分类变更）+ 名下有未清偿债务 "
                 "→ 应迁向 undecidable。\n\n")
    # 直接证据：产物的池段是否有"迁向不可判定留痕" > 0
    # （md 里没有直接数字，从"✓ 终局清算"和"变更轨迹"里读）
    lines.append("- **直接证据**：本轮产物**未**渲染"
                 "'迁向不可判定留痕 N 条'（该行在池段条件渲染，0 条不打印）"
                 "→ **间接可推断触发次数可能为 0**。\n")
    lines.append("- **离触发差多少**：看 D3 产物（135 calls / 4 圈 / "
                 "研究层 4 圈）—— 若研究层某子问题在圈 1 挂 deferral、"
                 "圈 2/3/4 都无 engagements 触碰，理应触发。产物里"
                 "'延迟债务'段可逐条核对。\n")
    lines.append("- **下一步设计方向**：选一道"研究层会连续多圈挂账、"
                 "且研究层圈数 ≥3"的题。例如"某开放领域有哪些实操坑，"
                 "分别怎么规避"这类需要拆解成多个子问题的题，"
                 "研究层容易在圈 1 挂多个 deferral、圈 2/3 顾不上全部。\n")
    return "".join(lines)


def _audit_mechanism_2(d):
    """机制二：no_push_when_idle=1 —— 空转类停止判据是否被推迟。"""
    lines = []
    lines.append("### 机制二 · no_push_when_idle=1\n")
    lines.append("**判据**：停止判据是"层内空转"（ing 复述 / 自省点名"
                 "未消化）时，**不应**被"未深入方向"推迟。\n\n")
    _hit = 0
    for e, reason in d["stop_reasons"].items():
        if "层内空转" in reason or "有新增但无推进" in reason:
            _hit += 1
            lines.append(f"- 层 `{e}`：stop_reason 含空转类 —— `{reason[:80]}`\n")
    if not _hit:
        lines.append("- **本轮无层触发空转类停止判据** → 该机制无观测机会。\n")
    lines.append(f"- **触发次数**：{_hit}\n")
    lines.append("- **离触发差多少**：需要一层在**非最后一圈**触发"层内空转"
                 "判据 + 同时还有未深入方向。D3 产物如无此情况，"
                 "下一步选一道"层内很容易空转"的题（例如：已经讲过、"
                 "没有新角度的封闭题）。\n")
    return "".join(lines)


def _audit_mechanism_3(d):
    """机制三：_reopen_closed_debt —— 被关的账要回来。"""
    lines = []
    lines.append("### 机制三 · _reopen_closed_debt\n")
    lines.append("**判据**：迁向 undecidable 后被救回（dec/partial），"
                 "被关的账要**重新挂一笔**（reopened_from 指向旧账）。\n\n")
    _reopened = [x for x in d["deferrals"] if x.get("reopened_from")]
    _to_ans = [x for x in d["decidability_log"] if x["to"] != "不可判定"]
    lines.append(f"- 有 `reopened_from` 的 deferral：**{len(_reopened)}** 条\n")
    lines.append(f"- 从 und 转出的 reclass：**{len(_to_ans)}** 条\n")
    if not _reopened:
        lines.append("- **本轮无复债** —— 该机制无观测机会。\n")
        lines.append("- **离触发差多少**：需要一道题里同时出现 "
                     "(a) 某 sub 迁向 undecidable（escalation / starve 触发）"
                     "(b) 之后又被救回。**这依赖机制一先被触发** —— "
                     "机制一是这个机制的前置。\n")
    return "".join(lines)


def _audit_mechanism_4(d):
    """机制四：stable_layers 2→3 —— 元层自然安住。"""
    lines = []
    lines.append("### 机制四 · stable_layers 2→3\n")
    lines.append("**判据**：元层悬置决定连续 3 圈同一批 → 自然安住。\n\n")
    _all_stop = d["stop_reasons"].get("all", "")
    if "自然安住" in _all_stop:
        lines.append(f"- 元层本轮**触发了**自然安住：`{_all_stop[:80]}`\n")
    else:
        lines.append(f"- 元层本轮未触发自然安住（stop_reason："
                     f"`{_all_stop[:80] or '（无）'}`）\n")
        lines.append("- **离触发差多少**：需要元层 ≥3 圈 + 每圈悬置决定"
                     "稳定。D3 产物元层跑了几圈可从"
                     "**实际走了 N 圈**字段读；若 N < 3 结构上不可达。\n")
    lines.append("- **下一步设计方向**：选一道**边界模糊、悬置明显**的"
                 "题（例如价值选择 / 制度设计），让元层能连续多圈"
                 "对同一批张力保持 stable。\n")
    return "".join(lines)


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("md", nargs="?", default=None,
                    help="产物 md 路径；不给取 outputs/ 下最新一份")
    ap.add_argument("--out", default=None,
                    help="审计报告落盘路径；默认 audit_zero_triggers_<ts>.md")
    args = ap.parse_args()

    md = Path(args.md) if args.md else _read_latest_packed()
    if not md or not md.exists():
        print("❌ 找不到产物 md。请显式传路径。")
        sys.exit(1)

    print(f"读入：{md}")
    d = _parse_md(md)

    parts = [
        f"# 零触发机制审计 · {datetime.now().isoformat()}\n\n",
        f"**输入产物**：`{md}`\n\n",
        "---\n\n",
        _audit_mechanism_1(d), "\n",
        _audit_mechanism_2(d), "\n",
        _audit_mechanism_3(d), "\n",
        _audit_mechanism_4(d), "\n",
        "---\n\n",
        "## 结论\n\n",
        "审计报告**不预设"应该触发"**。它只回答两个问题：\n\n",
        "1. 每个机制在**这一跑**里有没有触发（直接证据）？\n",
        "2. 若没触发，**离触发差什么**（差圈数 / 差题 / 差前置条件）？\n\n",
        "据此决定：\n",
        "- 若某项**结构上不可达**（如元层从不超过 2 圈）"
        "→ 是设计层级的问题，不是"跑错了题"。\n",
        "- 若某项**差一点**（如研究层 3 圈刚好差 1 圈）"
        "→ 下一步专门选一道题给它时间。\n",
        "- 若某项**完全无机会**（该跑没那个结构）"
        "→ 下一步按上面给的"设计方向"跑。\n\n",
        "★ 无论哪种情况，**结论都要先落在这份报告里**，再决定要不要动主文件。"
        "不许拍脑袋收紧判据。\n",
    ]
    text = "".join(parts)

    out = Path(args.out or f"audit_zero_triggers_"
                           f"{datetime.now().strftime('%Y%m%d_%H%M%S')}.md")
    out.write_text(text, encoding="utf-8")
    print(text)
    print(f"\n📁 已写：{out}")


if __name__ == "__main__":
    main()
```
