## 二、兑现了的四项

### 1. 角色排班（`next_role` 反馈环）— 完全兑现，证据最硬

四层全部从「摊开 × 3」变成正常排班，元层多给的那一圈也拿到了正确角色：

```
0    实际走了 3 圈（上限 3 圈）：摊开 → 转向 → 复裁
1    实际走了 3 圈（上限 3 圈）：摊开 → 转向 → 复裁
both 实际走了 3 圈（上限 3 圈）：摊开 → 转向 → 复裁
all  实际走了 4 圈（上限 4 圈）：摊开 → 转向 → 复裁 → 转向
```

对照上一轮：`0/1/both` 全是「摊开 → 摊开 → 摊开」，all 层四圈也全是摊开。

**而且这直接换了产出**：all 层第 4 圈在上一轮是 `新 & 0 / 新线头 0`（真·空转），本轮是 `3 / 3`。第三节会讲为什么这第 4 圈差一点就丢了。

### 2. 圈数上限口径（`rounds_cap`）— 兑现

上一轮写「实际走了 4 圈（**上限 3 圈**）」，本轮写「实际走了 4 圈（**上限 4 圈**）」。显示口径对齐了，产物不再自己跟自己打架。

### 3. 自省回流违例 3/4 → 0/4 — 兑现，但要打个折扣

上一轮三条违例全是「禁条目重现」，而且抄得清清楚楚：

```
上轮 both：禁条目重现：0端把入口位置标为"可碰但不碰"，1端把接收方标为"流程里没…
上轮 all ：禁条目重现："未摊开的面"若被识别，识别它所需的观察位正是它自己没有的位
```

本轮四层全部 `核对 1 条回流约束，违例 0 条`，没有一条 `禁条目重现`。

**折扣在哪**：【回流硬执行 · 最后一圈拦下的重现候选】这段在本轮 md 里**一次都没出现**，说明 `_drop_banned` 全程没开火——没有候选需要拦。所以「0 违例」有两种解释：(a) 模型真的改了；(b) 这趟本来就没重现。本轮数据分不开这两种。**也补一句**：这本来就在设计里，真有重现时会先被拦掉、再在核对里留痕，所以没人吃亏；只是这条改动的因果还不能算证实。

### 4. 0 层凑数被治住了

上一轮 0 层 `**质量线索**：candidates_backfilled(sc:7)`，本轮 0 层**没有任何质量线索**，自省也只点了「候选3偏复裁轮预设，略像补的」这种软判断。P2-2「宁可空不要凑」在 0 层这次生效了。

## 三、没兑现的三项

### 1. 凑数只治好了一层，both 层照旧

本轮 both 层仍然：

```
**质量线索**：candidates_backfilled(sc:6)
**质量评价**：候选后补（candidates_backfilled(sc:6)）
- 整体流程评价：候选7-12是补的，非展开长出；&2凑数；整体流程尚可但候选生成偏弱。
```

**原因不是改动没生效，是硬拦的机制只能覆盖一类凑数**。`_drop_banned` 拦的是「上一圈被点名的条目跨圈又出现了」。both 层这六条是**本圈新编的凑数**——新的法西斯式填充，不在任何禁令名单上，所以拦不到。

> 两类凑数是两条独立链路：**跨圈重现**（硬拦覆盖）和**当场新编**（只能事后标记）。本轮只改了前者。

### 2. all 层：自省点名凑数，检测器说没事

```
**质量评价**：判断正常，无质量线索
**自省**：
- 可疑候选：[3, 5]
- 备注：候选3、5偏自指补写；&2 极性对齐略凑；ing 未复述上游 view 原句。
```

自省明确点了两句是凑的，`quality_flags` 一条没出。**这是上一轮那个口径冲突的反面**：上一轮是「代码说 50% 复述 / 自省说没复述」（代码偏严），本轮是「自省说凑数 / 代码说没事」（代码偏松）。两边从来没校准过，谁都不服谁。

### 3. 三个 answer 仍然全是条件式，没有一条落地

- 子问题1：answer =「尚未算出」，只在列举要引用哪些证据（HumanEval / MMLU / API 调用量 / 企业采用率），`distance 0.9`——比上一轮的 0.6 还远。
- 子问题2：可判定通道为空，只留「双槽模型可能可用」，没展开。
- 遗留从 0 项变成 1 项。

诚实是诚实的（`诚实承认空：True` 四层全 True），但**两轮跑下来没有一条命题被真正兑现**，这不是某一处的 bug，是这套东西现在的整体水位。

## 四、新查出的问题

### 【新-1】all 层停止理由在撒谎：`ing 连续 4 圈复述` 名实不符 ⚠ 优先级最高

**现象**（本轮 md，all 层）：

```
| 1 | 摊开 | 3 | 2 | 0/0 | 0 |
| 2 | 转向 | 3 | 3 | 0/0 | 0 |
| 3 | 复裁 | 0 | 0 | 1/1 | 0 |
| 4 | 转向 | 3 | 3 | 0/0 | 0 |     ← 明显在产出

**螺旋停止**：ing 连续 4 圈复述（层内空转），螺旋停止
```

最后一圈刚产出 3 个新 &、3 条新线头，连续无新增计数是 0/0，却被判成「连续 4 圈复述 / 层内空转」。三个口径里只有它在说复述：

| 口径 | 本轮 all 层结论 |
|---|---|
| 代码实算 `ing 复述率` | 没打印 → 值为 0，没到阈值 |
| 模型自省 | `ing 复述（模型自判）：False` |
| 停止理由 | `ing 连续 4 圈复述` ← 只有它这么说 |

**机制**：`元DGTF-V1.21.55.py:7445`（`_run_layer`）/ `:8764`（`_run_one_round_B`）

```python
if view.carry:          # 本圈只要产出了自省回流约束
    carry_streak += 1   # 就 +1
else:
    carry_streak = 0
```

这个计数在注释里叫「自省判定复述/未裁的圈数」，**实际计的是「有回流注入的圈数」**。然后 `:7456` / `:9038` 把它和真正的复述计数取 max：

```python
_mi_effective = max(meta_idle_streak, _mi_from_view, carry_streak)
...
stop_reasons.append(f"ing 连续 {_mi_effective} 圈复述（层内空转）")
```

**推论**：自省在健康运行时每圈都会产出 carry。所以**一个自省正常的元层，`carry_streak` 必然一路涨到触发阈值，然后被贴上「复述」的标签**。这不是偶发，是指数为正的系统性误报。

**本轮差点就被它截断**：第 3 圈结尾已经满足触发条件（`layer_no=3 >= soft_max=3`，且 `_mi_effective>=2`）。救下来的是 `:7600` 那段元层闭环兜底——

```python
if (stop and entry == "all" and layer_no < _total_rounds):
    ... 清算不干净 → 推迟停止（streak 上限 1 次）
```

all 层当时是 `2/2 类张力未交代`，兜底判了一次「推迟停止」，第 4 圈才跑成。**如果那一圈的清算刚好是干净的，这层会在第 3 圈被一个假的「复述」理由截断，且不会有人知道**。

**建议改法**（三选一，我倾向 1+3）：
1. `carry_streak` 只在该 carry 的 `kind` 属于「复述/未裁」类时才 +1——现在的 `_build_carry` 已经带 kind，条件现成。
2. 或者把它从 `_mi_effective` 的 `max()` 里摘出去，另立一个独立的计数字段。
3. 停止理由的文案按实际来源分写，别再统一叫「ing 复述」。

### 【新-2】`ing 复述率` 的 0% 被显示逻辑吞了

`元DGTF-V1.21.55.py:9864`：

```python
if v.get("rephrase_ratio"):          # 0.0 是 falsy，直接不打印
    f.write(f"- ing 复述率（代码实算）：{v['rephrase_ratio']:.0%}\n")
```

本轮 all 层这一行没有，both 层有（`5%`）。**读产物的人分不清「算出来是 0%」和「压根没算」**——而这两件事的含义完全相反。改成 `is not None` 就一个字符的事。

### 【新-3】四象限对齐是一条从没亮过的通道

```
outputs/*.md 全部 10 份：四象限对齐 unaligned（匹配率 0%）（合法结果：两侧没有同一件事可对）
```

10/10，跨 4 个不同问题，全是 0%。这不是「未对齐是合法结果」，这是**结构上不可能对齐**。

`:1536` 的匹配判据：

```python
if _similar(pt, rt, 0.7):     # pt=修行层的 target，rt=研究层的 sub_question
```

`_similar` 用关键词集合，分母取 `max(len(ka), len(kb))`。修行层的 target 是「T6 判定权归属」这种短题，研究层的 question 是「AI是否应被视为与人对等的互动主体，这一判断在现有哲学和法学框架下能否达成共识？」这种长句——关键词集合大小差一个量级，比值永远到不了 0.7。

**这条通道现在完全是装饰性的。** 因为它挂着「未对齐合法」的免责说明，从来没人觉得它是坏的。要么换成按**语义角色/指向对象**匹配而不是字面相似，要么干脆把它从四象限降级成一个「交叉索引」。

### 【新-4】悬置生命周期允许同一实体同时占两个终态（复现，不是偶发）

本轮「研究延迟处理的」：

```
- AI是否应被视为与人对等的互动主体…能否达成共识？（handled）
- 当人面对AI时产生的失语或错位体验…？（handled）
- AI是否应被视为与人对等的互动主体…能否达成共识？（escalated）
- 当人面对AI时产生的失语或错位体验…？（dropped）
```

同一个子问题同时挂着 `handled` 和 `escalated`（另一个同时挂着 `handled` 和 `dropped`）。上一轮同样的事发生在「如何制定AI伦理规范」（handled + escalated）上。**两轮复现**，说明是状态机允许同实体多终态，不是跑飞了。

读产物的人没法判断以哪个为准。要么按最后一圈覆盖、要么显式记录状态迁移，别并列。
