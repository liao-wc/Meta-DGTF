## 二、★ 最重要的一条：三态一致率的尺子一直是错的

### 2.1 学科事实

原始一致率（percent agreement）**不计机会一致**。偏斜标签下两个「随便判」的人也会
高度一致。实证对照（Amazon 团队 2025，人 vs 各 LLM）：
**原始一致率 79% ↔ Cohen's κ 仅 0.34~0.44**。

而三态（`decidable / partial / undecidable`）**天然定序** ⇒ 该用 **ordinal**
距离函数（同一份数据 ordinal 与 nominal α 能差很多）。Krippendorff 的口径：
**α ≥ 0.800 可靠；0.667~0.800 仅支持暂定结论；< 0.667 不可靠（且 0.667 是下限不是目标）**。

### 2.2 ★ 用真跑数据实算（本版新增口径直接跑上一版产物）

`outputs/20261013_205109_…packed.json`（v1.23.29 真跑，6 条子问题、各 3 票）：

| 口径 | 读数 |
|---|---|
| 旧产物报的 `tri_state` | **3/6 = 0.500** |
| **原始配对一致率（本版复算）** | 3/6 = 0.500 |
| **ordinal Krippendorff α** | **−0.333** |
| 加权 κ | **0.000** |
| 判词（Krippendorff 阈值） | **不可靠（α<0.667）** |

★★ **原始 50% 看着「中等偏低」，机会校正后是 0 到负 —— 即那次的标签基本没有信号。**
这与项目此前的定性（「一致率 17~67%，是**标签可定义性边界**，不是工程质量问题」）
**并不冲突，但更狠**：不是「边界附近的噪声」，而是**在机会校正尺度上无信息**。
⇒ 结论更新：**不要再把原始一致率当中位数附近的「质量线」用**（v1.23.16 曾想把 0.5
当降档保护线，实测 p10=0.167 / 中位=0.333，那条线本来就会拦掉 54% 的跑）。

### 2.3 落地形态

- 产物里**原始一致率行改标题为「三态判决一致率（原始）」并显式加一句
  「★ 原始值不计机会一致，须与下行的机会校正指标一起读」**；
- 紧跟一行「**机会校正一致（ordinal）**：α = … · 加权 κ = …（n_unit=…）｜判词：…」；
- 再一行「**少数类一致（undecidable）**：k/n」—— 依据：**偏斜时多数类共识廉价，
  少数类一致才有信息**（本项目真正关心的是「判不出」这个少数类）。
- 样本不足（有效 unit < 2 或配对 < 2）⇒ **返回 None 并印「未测（样本不足）」**，
  不印 0 冒充读数（本项目的既有纪律）。

## 三、其余（第一/二批共 12 项）

### ② 测量尺度登记（Stevens 四重）
新增 `_READING_SCALE`：`tri_state_agreement`/`tier`/`csd_warning` = **ordinal**；
`duty.S` = **interval**（调和平均、零点非自然零点）；`semantic_entropy`/`touch_rate`
= **ratio**（有真零）。配 `scale_word_violations()`：**定序读数不许出现
「均值/平均/两倍/翻倍/百分比提升/标准差」**。
★ 这不是文风要求 —— 定序尺度的**差值无定义**，在其上做算术是测量学错误。
**未登记读数返回 `unknown`，不许默默当 interval 用。**

### ③ 停因级联（SHP）
`stop_priority()` 把停因映射到四级优先级：
**判定/收敛（职责增益收敛、结构饱和、悬置稳定）> 熵收敛（复述）> 无信息增益（停滞/空转）> 硬上限（体力耗尽）**；
`stop_cascade()` 排序并取出**主因**，写 `view.stop_primary`，产物另起一行
「【主因（最高优先级）】」。
★ **不变量：主因必须出现在全部触发里** —— 「报告的原因不能是没触发的那个」。
未匹配的文案落到最低档（**不静默丢弃**）。

### ④ 成本两分（SHP）
`LLM` 新增 `ops_*` / `eval_*` 两组计数，按 `cost_bucket(stage)` 分类
（判定类 stage 名单 `_LLM_EVAL_STAGES`）。**未登记的一律计 ops**（宁少算自测量 ——
把任务成本说小才是失真）。产物新增「**成本两分**」行。
不变量（判据）：`ops_calls + eval_calls == total_calls`。

### ⑤ CSD 早期预警（复杂系统）
`csd_indicators(series)` 算**方差 + lag-1 自相关**（+ 方差是否上升），
在层尾对逐圈 `new_amps` / `idle_stall` 序列算出读数，产物加一行。
★ **口径写死在文案里**：`「早期预警（CSD：方差 ↑ / AC1 0.46，有前兆；概率性评估，非预测）」`
—— 依据学科自己的反面证据：**六种 regime shift 机制里多数没有 CSD 前兆**，红噪声会虚警。
★ **它不参与任何停止判定**（本版零行为改动，纯读数）。

### ⑥ 截断两向记账（AgentExit）
`cut_two_way()`：截断时**同时**报「省下的圈」（正向）与「丢掉的 core 问项」（负向）。
★ 依据 AgentExit 的两向度量（Redundant Steps vs Progress Degradation）——
**只报一面必然误导**。与「只升不降的指标是自欺」同源。

### ⑦ 输入自检加规则类（llm-guard）
`input_red_flags()`：**不可见字符**（零宽/软连字符）+ **指令注入形态**（「忽略以上」等）
+ **预设式**（「为什么X」预设 X 成立）。★ 只取**规则类** —— llm-guard 的 ML 扫描器
会拉 transformers，与本项目「单文件零依赖」冲突。**不计入 LLM 调用**。

### ⑧ 言语行为标注（Austin/Searle）
`illocution_of()` / `illocution_dist()`：把行动按**承诺/断言/请求**分类。
★ 一份「行动清单」若**全是请求、没有承诺**，就不是方案而是祈使句堆砌 ——
产物会出「公文体风险」告警。首跑实测：**2/1/0/0**（有承诺，无告警）。

### ⑨ FMEA 可检测性（安全工程）
`fmea_detectability()`：FMEA 的 RPN = 严重度×频度×**可检测性**；
**不可检测的失败最危险**（不会出现在任何读数里）。产物**无条件输出**本节
（「没输出」会被读成「没有失败」，真相多半是「没被记下来」）。

### ⑩ 多样性预算（Ashby 必要多样性定律）
`diversity_budget()`：本跑实际动用的「层 × 通道」组合数。
★ 固定层×通道的多样性**有上限** —— 踩到上限时「跑得不好」不是工程缺陷，
而是**控制论上不可能**。这是**读数**（提示谨慎读结论），不是分数。
首跑实测：**层 2 × 通道 3 = 6 组合**。

### ⑪ nogoods 矛盾档案（ftl-beliefs）
新增 `nogoods.jsonl`（**append-only**）：被闸拒的候选（红线/无证据/不可验证）
与「用了但读数不达标」都留档。★ 依据：ftl-beliefs 的 nogoods ——
**矛盾只累积、不覆盖**（本项目老坑：静默覆盖 ⇒ 下次没人知道发生过矛盾）。
`nogood_record()` 抽成**纯函数**（理由见 §四 的 M15）。

★ **真跑还抓出 3 个真缺口（已修）**：
1. **「体力耗尽」型停因没有主因** —— 级联只写在 `_stop_reasons`，而**走满**时它返回空
   ⇒ 最需要主因的截断层反而没有主因。修：走满处也走一次级联（补口）。
2. **言语行为词表覆盖不足** —— 「核查/测量」被判「其他」。修：补动词。
3. **词表加入动名兼类后反而污染分类** —— 「完善统计」本是**请求**，被「统计」
   判成**承诺**（冒烟判据当场抓到）。★ 修：**只收动词性强的词**，
   动名兼类（统计/设计/发布/记账/登记/归档/监控…）一律不收 ——
   **宁可漏判成「其他」，不要误判成承诺**。

**探针里的关键数字**：偏斜夹具下 **原始一致率 0.900 vs α 0.294**（差 0.6）；
真跑数据 **0.500 vs α −0.333**。两条都直接支撑第 2 节。

### 本轮抓出并修掉的一个判据缺陷（M9 假绿）
「成本两分」最初把分类逻辑**内联在 `LLM.call` 里** ⇒ 判据只能看源码，
变异体（分类恒返回 ops）**假绿**。修法：抽成纯函数 `cost_bucket(stage)` 并改测它。
★ 通则（承接 v1.23.30/31）：**判据要能驱动到的逻辑，才有资格被当判据** ——
内联在一段大函数里的分支，只能靠「抽出来」变得可测。
