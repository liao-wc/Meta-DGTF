## 二、★ 任务书骨架里的一处真 bug（本档必须先修）

任务书 Step P6.1 给的检测代码：

```python
_n_explicit = sum(1 for a in out if "tier" in a and a["tier"] is not None)
if out and _n_explicit == 0:
    ...
```

**它在 `out` 上数，而 `out` 里每条锚点都已经被补过 `tier`（缺省 3）** ——
`"tier" in a` 恒为真、`a["tier"] is not None` 也恒为真，于是
`_n_explicit == len(out)`、`== 0` 永远不成立，**警告永远不触发**。

正解：在**补默认值之前的原始条目**上判。本版落点：

```
17276:  _n_explicit_tier = 0     # [v1.22.1 P6] 显式声明 tier 的条数
17293:  if str(a.get("tier") if a.get("tier") is not None else "").strip():
17294:      _n_explicit_tier += 1
17320:  if out and _n_explicit_tier == 0:
17321:      self._anchor_tier_warning = (
17325:      logger.warning("锚点 tier 全部缺省：%s", self._anchor_tier_warning)
```

冒烟里为此专门加了一条 `P6.1.c`：源码必须出现 `_n_explicit_tier`
（把「在原始条目上数」这件事本身钉住，而不是只钉「有警告字段」）。

「不许静默」，不是「不许继续」。

## 七、遗留与下一版候选

1. `tier` 缺省值 3 > 出厂 `tier_floor` 2 → **任何不写 tier 的锚点快照都会
   「载入了但一条都进不了引用表」**。本版只把它变成**可读的警告**；
   下一版可考虑：要么把缺省 tier 调到 ≤ floor，要么在 `_citation_table` 里
   对缺省 tier 做一次显式降级提示。**本版不动语义**（改缺省值 = 改行为）。
2. 警告只在「**全部**缺省」时触发。**部分缺省**（3 条里 1 条没写）目前
   完全静默 —— 下一版可补「部分缺省也计数提示」。
