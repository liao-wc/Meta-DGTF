## 二、遗留1 · 正交度：观测口径 → **受控实验**

### 2.1 为什么原口径**结构性不可判定**（不是 n 不够）

原判据是「组间 ≥ 组内」（组 = 题、组内 = 同题重复跑）。问题是：
**子问题集合每跑都重新拆解** ⇒ 「组内变异」里混进了**上游拆解**的变异，
而不只是被测量的那个机制（三票）的变异。v1.23.2 的 10 跑实测：
同题两跑的 `agree13` = **0.0 vs 1.0**（组内极差 1.0，而组间差只有 0.083）。
**再跑一百次也一样** —— 测得的是「拆解每次都不一样」。

### 2.2 修法：把被测量的机制**单独拿出来**

`_ab_tri_votes_v1233.py`：固定 **12 条**子问题 + 固定外部材料，
只让三票重投 **%d** 次。这是测量学里的 test–retest（固定刺激、重复测量），
与 `P2.4.a` 那次「采样 → 构造性证明」同族。

五臂 = W4 关/开 × 温度 0.0/0.7 + **证据反事实**；
★ 温度 0.7 那一对是**负对照**（注入随机性，看 ICC 会不会掉）。

### 2.3 结果

| 臂 | W4 | 温度 | agree12 | agree13 | agree23 | 样本 |
|---|---|---|---|---|---|---|
| `w4_off_t0` | 关 | 0.0 | 0.573 | 0.531 | 0.75 | 96 |
| `w4_on_t0` | 开 | 0.0 | 0.573 | 0.229 | 0.49 | 96 |
| `w4_off_t7` | 关 | 0.7 | 0.612 | 0.718 | 0.667 | 85 |
| `w4_on_t7` | 开 | 0.7 | 0.518 | 0.459 | 0.292 | 85 |
| `on_swap_t0` | 开 | 0.0 | 0.583 | 0.531 | 0.427 | 96 |

**判据「组间 ≥ 组内」的两个读法**（都列出，主判据写明）：

| 读法 | Δ(t0) | 结果 | 主判据? |
|---|---|---|---|
| **F 检验**（标准 / 与 ANOVA 一致） | -0.323 | F = 15.1，t = 3.89 ⇒ 可判定 ✅ 组间 ≥ 组内（F = 15.1 ≥ 1；|Δ|/SE = 3.89） | ✅ 主判据 |
| 个体级 σ（更苛刻的读法） | -0.323 | \|Δ\|/σ = 0.4 ⇒ 可判定 ✗ 组内 > 组间（|Δ|/σ = 0.4） | ✗ 不作主判据 |

★ **为什么 F 检验是主判据**：「组间 ≥ 组内」在实验设计里的标准含义就是
  MS_组间 ≥ MS_组内（ANOVA），等价于配对 t 的 \|Δ\| ≥ SE = σ/√n。
  「\|Δ\| ≥ σ_个体」是更苛刻的另一个读法 —— 对**二值**指标
  （每条子问题上的差 d ∈ {−1, 0, +1}）几乎不可能成立；它量的是
  **效应异质性**（效应是否在每条子问题上同号同幅），不是噪声。
  两个都报，避免「换个口径把它做绿」的嫌疑。

★ 温度 0.7 臂作为**负对照**的读数：可判定 ✅ 组间 ≥ 组内（F = 1.74 ≥ 1；|Δ|/SE = 1.32）（ICC 的判别力见下表）

**功能读出**（这才是「正交」该量的东西）：

★ 原指标「第三票改变多数结论」在 3 票制下**恒为 0**（1、2 票一致时
  第三人永远改不了多数）—— 恒不触发的指标是自欺，已换掉。

| 臂 | 1、2 票一致的条数 | 第 3 票唱反调 | 唱反调率 |
|---|---|---|---|
| `w4_off_t0` | 55 | 11 | 0.2 |
| `w4_on_t0` | 55 | 34 | 0.618 |
| `w4_off_t7` | 52 | 3 | 0.058 |
| `w4_on_t7` | 44 | 26 | 0.591 |
| `on_swap_t0` | 56 | 26 | 0.464 |

**最终判决变化率**（同一 (子问题, 重复) 下 W4 开 vs 关，t0）：**28 / 96 = 0.292**

**证据反事实**（同批子问题、同样 W4 开，只把外部材料换成**相反**的说法）：
第 3 票标签变化 **60 / 96 = 0.625** ⇒ **外部材料真的在驱动第三票**

### 2.4 结论（写死，免得读者自己推断）

1. **判据可判定了**：主判据（F 检验）在 t0 上 F = 15.1（t = 3.89）⇒ **组间 ≥ 组内成立**；t7 上 F = 1.74 仍 ≥ 1。
2. **W4 的设计目的达成**：ON 臂第三票的**唱反调率 0.618**，而 OFF 臂只有
   **0.200** —— 第三票从「橡皮图章」变成**真的独立裁判**；最终判决在
   **29.2%** 的条上被它改变。
3. **构造性证明**：把外部材料换成相反说法后，第 3 票 **62.5%** 的条目改判
   ⇒ 它真的在**读外部材料**（不是只在读池内产物）。
4. **诚实记账（不是遗留）**：原报告里「第三票与前两票一致性更低」这句
   **表述不成立**（`agree13` 与 `agree23` 同时下降，而 `agree12` 基本不动）
   —— 「更不一致」不是正交的判据；本版改用**唱反调率 + 判决变化率 +
   证据反事实**三个功能量，它们都是可判定的。

## 三、顺带修掉一类静默 bug：三票判决读**模型返回的 id** 从不校验

### 3.1 发现路径

受控实验里某票返回的 `judgments[].id` 是 **0 起**（0..n−1），而引擎按
**1 起**对齐（`for i, s in enumerate(subs, 1)`）⇒ 该票**整票错位一格**：
第 2 条子问题拿到本该给第 1 条的标签，第 1 条**没人投**。
既不抛错、也不留痕 —— 读者从产物上完全看不出来。

**频度（受控实验实测）**：

| 臂 | 1 起 | **0 起** | 越界 | 空票 | 非对象 |
|---|---|---|---|---|---|
| `w4_off_t0` | 24 | **0** | 0 | 0 | 0 |
| `w4_on_t0` | 24 | **0** | 0 | 0 | 0 |
| `w4_off_t7` | 23 | **1** | 0 | 0 | 0 |
| `w4_on_t7` | 23 | **1** | 0 | 0 | 0 |
| `on_swap_t0` | 24 | **0** | 0 | 0 | 0 |

⇒ **温度 0.0（生产实参）下 0 / 72 = 0**；温度 0.7 下 **2 / 48**。
★ 诚实定性：这是**潜在**的静默失败面（今天生产固定传 0.0 所以没触发），
  但「模型给的 id 不可信」没有任何防护，温度参数一旦被调就**无声腐蚀**
  三态判决、`stability` 与 `tri_consensus`。修它成本极低，收益是
  **消掉一整类静默失败**。

### 3.2 同族共 3+1 处（审计 L 类一次性扫出来）

| # | 位置 | 问题 | 修法 |
|---|---|---|---|
| 1 | `_adjudicate_sub_tristate_multi` | 多票读 id 不校验 | 过 `_normalize_judgment_ids` |
| 2 | `_adjudicate_sub_tristate` | 单票同上 | 同上 |
| 3 | `_parse_subs` / `_decompose_from_pool` | **子问题 id 直接取自模型**（0 起 / 带洞 / 重复），而下游一律按 1..n 用 | 新增 `_canonical_sub_ids`按位置重编号 |
| 4 | 产物 `votes[].voter` | 记的是**位置**（`enumerate(vs)`）—— 丢一张票就重新编号 ⇒ `agree13` 比的是**别的 prompt 对** | 记**真票号** |

★ 3 与 4 都是写 id 归一化判据时**被自己的判据扫出来的**（审计探针的新
  一类判据 `L2`）。这正是「一类判据」的价值：修一处不算修，
  要能拦下**同族的下一次**。

### 3.3 验收期又抓到的第 5 处：**空票被重复计成「越界弃票」**

把「0 起归一」接进多票路径时，第一版写成 `elif _jb is None: _id_bad += 1`
—— 而 `_normalize_judgment_ids({}, n)` 对**空 dict** 也返回 `None`。
于是一张空票被数两次（`_empty_votes` 一次 + `_id_bad` 一次），池级留痕印出
「**1/3** 票可用（空票 1 张；id 越界弃票 1 张）」，**可用票数少数一张**。

发现路径：`_probe_v1231_left.py` 的 `L4.2`（「留痕必须写清可用几票」）
当场判红。修法：空票只由 `_empty_votes` 计，`越界` 才计 `_id_bad`。
★ 这是「判据的价值」的又一次实证：一条 8 个月前写的判据，
  拦住了一次新改动引入的重复计数。

## 四、遗留2 · 思考分档的实际收益（录播式 A/B）

### 4.1 设计

① **录播**：包住 `LLM.call`，跑真实流程，把每个 stage 的**真实输入**
（system / user / 温度 / max_tokens / json_mode）原样存下来。
② **回放**：同一输入分别跑 `thinking=disabled` 与 `thinking=enabled`，
两臂除 thinking 外**逐字相同**。
③ **度量**：JSON 合法率 / 输出规模 / 延迟（客观）+ **独立评分**（0–2）。
④ **判据：等效检验（TOST）**，margin = 0.3。区间落在 ±margin 内 = **无收益（等效）**；下界 > margin = 有收益；上界 < −margin = 有损；
   跨界 = 不可判定（并报本 n 的 MDE）。
★ 「无收益」是**结论**，不是「没测出来」—— 这是等效检验与「p > 0.05」
  的区别。

★ **覆盖 15 个 yaml 键的全部**：录播本身只触达 10 个（`_decompose_normal` /
  `_decompose_hybrid` / `_decompose_koan` 由**池的三态状态**分派，
  `_ask_missing_polarity` / `_check_structure_saturation` 要特定条件），
  余下 5 个用 `_ab_thinking_direct.py` **直接驱动方法本身**补录 ——
  走的是同一段 prompt 构造 + 同一个 `llm.call(stage=…)`，输入仍是真实输入。
  ★ 通则：**「有接线」≠「这跑走得到」**。

## 十二、经验教训

1. ★ **「不可判定」往往是口径错，不是样本少**。观测式的「组间 ≥ 组内」里，
   组内变异混进了**上游机制的变异**（子问题每跑重拆）—— 这种口径
   **结构性不可判定**，跑一万次也一样。正解是**受控实验**：固定刺激、
   只让被测机制重投。
2. ★ **换口径前先问「这个指标在结构上能不能变」**。本版第一版写的
   「第三票改变多数结论」在 3 票制下**恒为 0**（两人一致时第三人
   永远改不了多数）—— 与「只升不降的指标是自欺」同族。
3. ★ **变异体必须打在判据读的那个东西上**（本项目第 N 次）：温度 0.7 臂
   作为负对照，用来证明 ICC 有判别力。
4. ★ **判据的锚不能写死会变的东西**：`check_v1232_audit` 把被测文件写成
   `元DGTF-V1.23.2.py` ⇒ 升版后「smoke SRC 指向本版」必判红。
   改为取**已加载模块的 `__file__`**。
5. ★ **一类判据 > 一处修复**：id 归一化做成审计 L 类后，**当场又扫出两处**
   （子问题 id、`voter` 位置）—— 只修「看到的那一处」会漏掉同族。
6. ★ **注入器一次只改自己那一档，但会用别档的锚**：`_mk_v1232_smoke_checks`
   从 `def check_v1232_audit` 换到 MARK ⇒ 排在它前面的修改会被抹掉。
   修别档必须改**那一档的注入器**，不是生成器。
7. **等效检验 ≠ 没测出差异**：「无收益」要给出区间在 ±margin 内的证据，
   不能写成「p > 0.05」。
