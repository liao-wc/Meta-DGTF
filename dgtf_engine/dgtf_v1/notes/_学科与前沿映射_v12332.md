## 一、最痛的三处，学科里早有正解

### 1.1 三态一致率口径错了 —— 应改用 **Krippendorff's α / Cohen's κ**（A）

**现状**：元DGTF 报「三态判决一致率 50%（3/6）」，并在文档里定性为
「标签可定义性边界，不是工程质量问题」（v1.23.28 §7.13）。

**学科事实**（评分者一致性研究，1960 年至今）：
- **原始一致率（percent agreement）不计机会一致**，在标签**偏斜**时会严重误导。
- 实证对照表（Amazon 团队 2025，人 vs 各 LLM 打分）：
  原始一致率 **79%** 对应的 Cohen's κ 只有 **0.34~0.44**，Krippendorff α(nominal) **0.35~0.42**。
  —— 4 个百分点的「高一致」在 κ 下是「中等偏低」。
- 阈值（Krippendorff 本人的口径）：**α ≥ 0.800 才算可靠**；
  **0.667 ~ 0.800 只支持 tentative 结论**；**0.667 是下限，不是目标**。
- 统计量选择依**评审结构**定：2 人用 κ；固定 N 人用 Fleiss' κ；
  任意人数 + 缺失值 + 多尺度用 **α**（α 的优点是**支持定序距离函数**）。

**为什么这条最重要**：元DGTF 的三态（`decidable / partial / undecidable`）
**天然是定序的**（有顺序：判得出 → 部分 → 判不出）⇒ 应该用
**ordinal α**（或 weighted κ），而不是原始一致率，也不该用 nominal α
（同一份数据 nominal 与 ordinal α 能差很多）。

**★ 结论：现有「一致率 17~67%，是标签定义边界」这个结论，可能建立在错误的尺子上。**
先改口径再谈定性 —— 否则「分母不稳」的判断本身就不稳。

- **落点**：`tri_state` / `tri_consensus` 的一致率计算 + 产品头部读数。
- **代价**：小（纯统计，几十行）。
- **红线**：✅ 完全一致 —— 本项目「同一把尺子」「锚不能是会变的东西」就是这条。
- **附带可做**：**报告 rare-class 一致**（偏斜时共识廉价，罕见类一致才是真信号），
  这正是元DGTF 需要区分「判不出」这种少数类的原因。

### 1.2 停止判据在统计上「不合法」—— 需要 **anytime-valid（e-value / 置信序列）**（A）

**学科事实**（Ville 1939 → Ramdas/Grünwald/Vovk/Shafer 2023 复兴 → SAVI 2025 workshop）：
- 传统检验**不许随时看随时停**：反复检验再停会让假阳率暴涨。
- **anytime-valid** 的定义：对**任意（数据依赖的）停时 τ** 都有 `E[φ_τ] ≤ α`。
  构造方式：**非负鞅**（e-value / e-process / confidence sequence）；
  由 **Doob 可选停时定理**给出保证。
- Koning & van Meer (arXiv 2501.03982, 2025)：**「anytime validity is free」** ——
  任意 N 样本的检验都能改造成 anytime-valid 且不损失功效；
  未拒绝时的检验值可直接当作**后续检验的显著性水平**（optional continuation）。
- 已有 LLM 应用：**CITE**（Anytime-Valid Statistical Inference in LLM Self-Consistency）
  用 e-process 给「自洽多数」发**证书**：在任意数据驱动停止下，假证书概率受控。
  MMC（Martingale Majority Certificate）同源。

**为什么元DGTF 需要它**：本项目的停止判据全是**边跑边判**（每圈检查「连续 2 圈无新增」等），
这正是 optional stopping 的典型场景 —— **现在没有任何有效性保证**。
而且「三态一致率」本身就是个**边采样边估计的比例**，用固定样本公式算它是不对的。

- **落点**：① 停止判据的理论包装（`_stop_reasons` 的置信口径）；
  ② 三态一致率改成**置信序列**（随时可读、随时可停）；
  ③ 冒烟的一致性判据可用 e-value 写。
- **代价**：中（要引入鞅/e-process 的具体构造；可先用最简单的「测试鞅/betting martingale」起步）。
- **红线**：✅ 不涉及打分；只把「我什么时候敢停」变成**有保证**的事。
- **注意**：这**不是**给悬置打分 —— 只对**可测量**（如一致率、职责度）用。

### 1.3 「结构饱和度」判据可以更早 —— **临界慢化（CSD）/ 早期预警信号（EWS）**（B）

**学科事实**（统计物理 van Hove → Landau；生态学 EWS 体系）：
- 系统接近**临界转变**时**恢复速率下降**（主导特征值 → 0）⇒ 时间序列出现
  **方差上升 + lag-1 自相关上升**（还有偏度上升、flickering）。
- 已在生态（湖泊营养化、荒漠化）、气候（古气候突变）、生理（心律失常）、
  金融（崩盘前波动率自相关上升）反复验证。
- **★ 但必须同时引用反面**：约六种 regime shift 机制中，**只有一部分有 CSD 前兆**
  （缓慢驱动逼近临界点「有」；慢-快循环「无」；极端事件长瞬态「无」；驱动阶跃「无」）；
  **红噪声会造成虚警或掩盖信号**（PhysRevX 14, 021037）。
  结论口径：CSD 指标应被读作「**韧性变化的概率性评估**，不是迫近崩溃的确定性预测」。

**为什么元DGTF 用得上**：本项目的「结构饱和度判定」（both 层那条）
现在依据的是「连续 N 圈无新维度」——这是**事后**判据。
每圈已有可算的时间序列（`new_amps` / `new_threads` / `idle_stall`）
⇒ 可直接算 **variance 与 AC(1)** 作**早期预警**，比「连续无新增」更早看到「这层快饱和了」。

- **落点**：`both` 层的 `sat` 判据 + 各层的停滞读数。
- **代价**：小（滑动窗口 + 方差/AC(1)，纯规则）。
- **红线**：✅ 但**必须**按学科口径写清「这是概率性评估，不是预测」，且要**两向报**
  （有前兆 / 无前兆）—— 与「不许只升不降」同源。

## 二、测量学：把「读数 vs 分数」正式化（A）

**学科事实**（Stevens 1946 四重尺度；后续 Narens/Luce/Alper 的公理化）：
| 尺度 | 允许的运算 | 中心趋势 |
|---|---|---|
| 定类 nominal | 只有相等/不等、集合成员 | 众数 |
| 定序 ordinal | 加序关系（＞＜）；**差值无意义** | 中位数 |
| 定距 interval | 加减；**比值无意义**（零点任意） | 均值/标准差 |
| 定比 ratio | 全部四则运算（有真零） | 全部 |

**元DGTF 现状**：项目已有很强的直觉（「读数不是分数」「不许合成一个分」
「同一把尺子」「只升不降的指标是自欺」），但**没有形式化**。

**可直接落地的一条判据**：给每个读数**标注尺度类型**，并**按尺度限制允许的运算**：
- `semantic_entropy` ∈ [0,1] 且有真零（熵为 0 就是无分歧）⇒ **定比**；
- `duty.S` 是调和平均、分母无真零 ⇒ **定距**（可以算差、**不可以**说「A 是 B 的两倍」）；
- `tri_state` 三态 ⇒ **定序**（可以做 α(ordinal)，**不可以**求算术平均）；
- `tier`（锚点分级）⇒ **定序**；
- `touch_rate` 覆盖率 ⇒ **定比**（0 = 从未触及）。

★ 落地形式：一个 `SCALE_KIND = {"duty.S": "interval", "semantic_entropy": "ratio",
"tri_state": "ordinal", ...}` + 一条**判据**：产品里凡声明为 ordinal 的读数，
渲染层**不得**出现「均值/倍数/百分比提升」这类措辞（可用变异体钉住）。
这比再写十条散文式的「不许打分」有用得多 —— **它是可执行的红线**。

- **代价**：小。
- **红线**：✅ 正是「悬置不打分」「未对齐合法」的形式化表达。

（Reiter default logic / McCarthy circumscription / defeasible reasoning）的典型场景。

  与元DGTF 的 `support / attack / revoke_sources` 同构；
  可把「什么能推翻什么」写成**显式规则表**，而不是散在代码里。
- **落点**：`belief_transition` 的迁移条件。
- **代价**：小。

## 六、语言学 / 语用学（B，直接治「未生」与「悬置」的判据）

- **格莱斯会话含义（Grice）**：「此处未生」若只是**回避**（flouting 不配合），
  在语用上就是**不合作**；本项目已有 `unsaid_is_escape` 判据（判逃避）——
  等于已在做 Grice 的「合作原则」检查。建议**显式命名**，并加**质量准则**检查：
  说了但无证据 = 违反 Quality；说了但与问题无关 = 违反 Relation。
- **预设（presupposition）与预设失败**：不少「回答不了原问题」是**预设失败**
  （问题预设了「主体已定义」等）。元DGTF 的 `input_sanity` 只查符号歧义，
  **不查预设** ⇒ 这是「原始问题与输出错位」的一个真实来源。
- **言语行为论（Austin/Searle）**：区分 `locution`（说了什么）/
  `illocution`（在做什么：断言/承诺/提问）/ `perlocution`（效果）。
  「决议书」里的每条行动应**显式标注言语行为类型**（承诺 vs 断言 vs 请求），
  否则「行动清单」会退化成祈使句堆砌。**这正好解释**上次真跑的行动清单
  为何读起来像公文体（全是 illocutionary 请求，没有断言支撑）。

## 八、控制论 / 系统论（**这一条可能改变元DGTF 的根本判断**）

### 8.1 Ashby 必要多样性定律（Law of Requisite Variety）★
> **控制器可用的状态多样性 ≥ 被控系统的扰动多样性**，否则无法把系统维持在目标域内。

**推论（针对元DGTF）**：**固定的四层 + 固定通道，其多样性是有限的**。
当问题复杂度超过这个上限时，**不是「跑得不好」，而是控制论上不可能**。
这给两件事提供了理论依据：
- **为什么「砍层」有风险**（减少多样性 ⇒ 直接触及上限）；
- **为什么「模式多样性」不是冗余**（parallel_mode A~H 的不同 stage graph
  正是**多样性预算**）。⇒ 上一版 B1 把自动路径收敛到 `serial/B/C` 是**对的**
  （省的是「那次调用」），但**不应该顺手把它们从可达集合里删掉** ——
  它们是**备用多样性**。★ 这条正好呼应 v1.23.30 的决定（D~H 保留为显式选项）。
- 可落地：**「多样性预算」读数** —— 每跑报「本跑实际动用的层×通道×模式组合数」，
  低于某门槛时提示「多样性可能不足，谨慎读结论」。**这是读数不是分数。**

### 8.2 其他
- **Lyapunov 稳定性**：与 CSD 同源（主导特征值→0），可合入 1.3。
- **Viable System Model (Beer)**：必要性通路 + 递归结构 —— 与「四层 + 元层递归」同构，
  可借其**「审计通道必须独立于执行通道」**原则：元DGTF 的 `self_check` 已独立，可显式声明。
- **闭环控制**：LoopGain 的误差信号三态（收敛/停滞/发散）= 控制器设计常识，见 `_开源映射` 1.1。

## 九、信息论 / 热力学（B，治「产物臃肿」）

- **率失真理论（rate–distortion）**：给定位数下最优失真 ⇒ 直接支撑
  「产物 compact 带预算」（`_开源映射` 3.2），并且给出**正确的取舍口径**：
  **不是「压得越短越好」，而是「给定预算下的最优表示」**——
  正对上 ACE 的教训（压缩过头 ⇒ 准确率 66.7→57.1）。
- **最大熵 / 交叉熵**：`semantic_entropy` 已是熵；可显式说明它测的是**说法的分布**，
  不是「主张对不对」（防误读）。
- **Landauer 原理 / 热力学代价**：隐喻层 —— 「不擦除可换低能耗」（本项目不删数据的做法，
  在工程上恰好也是「可回溯 = 可审计」的来源）。**只作解释，不做机制。**

### 明确**不**采纳（连同上一份的理由）
- AGM 命题逻辑实现、llm-guard 的 ML 扫描器（拉 transformers）、
  ABES 的 RL 学衰减率（样本不足）、信念加第五态 `STALE`（改语义）。
- **新增不采纳**：把 CSD 当**预测器**用（学科自己的反面证据：六种机制里多数无前兆、
  红噪声会虚警）—— 只能当**概率性评估**；
  把认知科学术语当机制加（SOAR/ACT-R/CLT 只做**命名与解释**，不新增层）。

## 十一、三条从学科里抄来的「纪律」（比机制更值钱）

1. **先问尺子对不对，再问数高不高**（测量论 + 评分者一致性）——
   元DGTF 有「同一把尺子」的说法，但没有**尺子的类型学**。
2. **允不允许随时停，决定了统计量怎么算**（anytime-valid）——
   「边跑边判」不是实现细节，它改变了**有效性的定义**。
3. **早期预警是概率性评估，不是预言**（CSD 的反面证据）——
   这条与本项目「证不出就诚实写：这是观察，不是定理」完全同源。
